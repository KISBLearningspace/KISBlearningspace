2Study Notes

Basic graphs (x in radians). y = sin x and y = cos x: period 2π, amplitude 1, range −1 ≤ y ≤ 1. The cosine curve is the sine curve shifted left by ⟦π|2⟧. y = tan x: period π, range all real numbers, vertical asymptotes at x = ⟦π|2⟧ + kπ.
General form.
y = a sin(b(x − c)) + d
• amplitude = |a|  • period = ⟦2π|b⟧ (for tan: ⟦π|b⟧)  • midline y = d  • horizontal shift c to the right  • maximum = d + |a|, minimum = d − |a|. The same applies to cosine. (The IB writes the shift as (x + c), so the shift is left by c.)
Example 1. For y = 3 sin 2x + 1, find the amplitude, period, midline and range.
  1. Compare with y = a sin(bx) + d. a = 3, b = 2, d = 1.
  2. Amplitude. |a| = 3.
  3. Period. ⟦2π|b⟧ = ⟦2π|2⟧ = π.
  4. Midline. y = d = 1.
  5. Range. From d − a to d + a: 1 − 3 = −2 to 1 + 3 = 4.
Answer: Amplitude 3; period π; midline y = 1; range −2 ≤ y ≤ 4.
Example 2 (phase shift). Describe y = 2cos(x − ⟦π|3⟧).
  1. Compare with y = a cos(b(x − c)) + d. a = 2, b = 1, c = ⟦π|3⟧, d = 0.
  2. Amplitude and period. Amplitude 2; period ⟦2π|1⟧ = 2π.
  3. Shift. x − ⟦π|3⟧ means the graph moves right by ⟦π|3⟧.
  4. First maximum. y = cos x has a maximum at x = 0, so the shifted graph has its first maximum at x = ⟦π|3⟧, with y = 2.
Answer: Amplitude 2; period 2π; shifted right ⟦π|3⟧; first maximum at (⟦π|3⟧, 2).
Example 3 (from a graph). A cosine-type graph has maximum 7 at t = 0, minimum 1 and period 8. Find its equation.
  1. Write the form. y = a cos(bt) + d (a cosine starts at its maximum, so there is no shift).
  2. Midline d = average of max and min. d = ⟦7 + 1|2⟧ = 4.
  3. Amplitude = half the difference. a = ⟦7 − 1|2⟧ = 3.
  4. b from the period. ⟦2π|b⟧ = 8, so b = ⟦2π|8⟧ = ⟦π|4⟧.
  5. Check. At t = 0: 3cos 0 + 4 = 7 ✓
Answer: y = 3cos(⟦π|4⟧t) + 4
Example 4 (Ferris wheel). A wheel of radius 10 m has its lowest point 2 m above the ground and one turn takes 40 s. Starting at the bottom, h = 12 − 10cos(⟦π|20⟧t). When is the rider first at a height of 17 m?
  1. Where do the numbers come from? The centre is 2 + 10 = 12 m high. Starting at the bottom means −cos. The period 40 gives b = ⟦2π|40⟧ = ⟦π|20⟧.
  2. Set h = 17. 12 − 10cos(⟦π|20⟧t) = 17.
  3. Isolate the cosine. −10cos(⟦π|20⟧t) = 5, so cos(⟦π|20⟧t) = −⟦1|2⟧.
  4. First solution. The first angle with cosine −⟦1|2⟧ is ⟦2π|3⟧, so ⟦π|20⟧t = ⟦2π|3⟧.
  5. Solve for t. t = ⟦2π|3⟧ × ⟦20|π⟧ = ⟦40|3⟧ ≈ 13.3.
Answer: t ≈ 13.3 s
Example 5 (tangent). Describe y = tan 2x: period, asymptotes and zeros.
  1. Period. tan x has period π, so tan 2x has period ⟦π|2⟧.
  2. Asymptotes. tan x has asymptotes at x = ⟦π|2⟧ + kπ, so set 2x = ⟦π|2⟧ + kπ and divide by 2: x = ⟦π|4⟧ + ⟦kπ|2⟧.
  3. Zeros. tan 2x = 0 when 2x = kπ, so x = ⟦kπ|2⟧.
Answer: Period ⟦π|2⟧; asymptotes x = ⟦π|4⟧ + ⟦kπ|2⟧; zeros x = ⟦kπ|2⟧ (k an integer).
Finding an equation. ① midline d = ⟦max + min|2⟧. ② amplitude a = ⟦max − min|2⟧. ③ b = ⟦2π|period⟧. ④ choose cosine if the graph starts at a maximum, sine if it starts on the midline going up; then fix the shift.
Think: ① Why does doubling b halve the period? ② What changes in the graph when a is negative? ③ Why can the same curve be written with sine or with cosine?

3History & Facts

  • Joseph Fourier (1807): showed that any periodic pattern can be built from sine and cosine waves, the base of modern signal processing.
  • Tide predictions (1800s): Lord Kelvin built a machine that added sine waves to predict tides.
  • Thai river tides: the Chao Phraya at Bangkok has daily tides, which are predicted with sinusoidal models.
  • Fact: daylight hours in a city over one year follow a sine curve, with the period one year.

5Real-World Applications

  • Tides and ocean waves: the depth of water in a harbour follows a sine model with period about 12.4 hours.
  • Daylight hours: a sine curve with period one year; amplitude grows with latitude.
  • Sound and music: a pure note is a sine wave; pitch is the frequency, loudness is the amplitude.
  • Electricity: alternating current has the form V = V₀ sin(2πft).
  • Engineering and amusement parks: Ferris wheels, pendulums and springs.

7Classwork & Homework

Classwork

  1. State the amplitude, period and range of y = 4 sin(3x) − 1.
    AnswerAmplitude 4, period ⟦2π|3⟧, range −5 ≤ y ≤ 3.
  2. Find the maximum value and where the first maximum of y = 2cos(x − ⟦π|4⟧) + 1 occurs for x ≥ 0.
    AnswerMaximum 3 at x = ⟦π|4⟧.
  3. A sine-type graph has maximum 6, minimum −2 and period 10. Write an equation y = a sin(bx) + d, assuming it starts on the midline going up.
    Answerd = 2, a = 4, b = ⟦π|5⟧: y = 4 sin(⟦π|5⟧x) + 2.
  4. State the period and the equations of the asymptotes of y = tan 2x, for 0 ≤ x ≤ π.
    AnswerPeriod ⟦π|2⟧. Asymptotes x = ⟦π|4⟧ and x = ⟦3π|4⟧.

Homework

  1. The height of the tide in metres is h = 5 + 2 sin(⟦π|6⟧t), where t is in hours. Find the highest and lowest heights and the period.
    AnswerHighest 7 m, lowest 3 m, period 12 hours.
  2. For the tide in HW 1, find the height at t = 2.
    Answer5 + 2 sin(⟦π|3⟧) = 5 + √{3} ≈ 6.73 m.
  3. Solve cos 2x = ⟦1|2⟧ for 0 ≤ x ≤ π.
    Answer2x = ⟦π|3⟧ or ⟦5π|3⟧, so x = ⟦π|6⟧ or ⟦5π|6⟧.
  4. Write y = 3 sin x as a transformation of y = sin x, and give its range.
    AnswerVertical stretch of scale factor 3; range −3 ≤ y ≤ 3.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] f(x) = 3cos 2x + 1, for 0 ≤ x ≤ 2π.
(a) Write down the amplitude and the period of f. [2]
(b) Write down the maximum and minimum values. [2]
(c) Solve f(x) = 4. [2]
Mark scheme(a) A1 amplitude 3; A1 period π.
(b) A1 maximum 4; A1 minimum −2.
(c) M1 cos 2x = 1; A1 x = 0, π, 2π.
Question 2 [5 marks] The graph of y = a cos(bx) + d has a maximum point at (0, 5) and the next minimum point at (⟦π|2⟧, −1). Find a, b and d.
Mark schemeM1 d = ⟦5 + (−1)|2⟧; A1 d = 2; A1 a = 3; M1 half period = ⟦π|2⟧ so period π; A1 b = 2.

Paper 2 style (GDC allowed)

Question 3 [9 marks] The depth of water in a harbour is modelled by d(t) = 6 + 2.5 sin(⟦π|6⟧t), where d is in metres and t is the time in hours after midnight.
(a) Write down the maximum and minimum depths. [2]
(b) Write down the period. [1]
(c) Find the depth at 02:00. [2]
(d) A boat can enter when the depth is at least 7 m. Find the times between 00:00 and 06:00 when this is true. [4]
Mark scheme(a) A1 8.5 m; A1 3.5 m.
(b) A1 12 hours.
(c) M1 d(2) = 6 + 2.5 sin(⟦π|3⟧); A1 8.17 m.
(d) M1 2.5 sin(⟦π|6⟧t) ≥ 1, so sin(⟦π|6⟧t) ≥ 0.4; A1 t = 0.786 (first solution, 00:47); A1 t = 6 − 0.786 = 5.21 (05:13); A1 the boat can enter from about 00:47 to 05:13.
