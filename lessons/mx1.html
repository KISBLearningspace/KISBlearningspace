Guiding questions

  • What is a matrix, and why is it a useful way to store information?
  • How do we say how big a matrix is, and how do we name one entry?
  • When are two matrices equal?

Learning outcomes

  • Define a matrix and its rows, columns and elements.
  • State the order m × n of a matrix and the number of elements.
  • Name the element in a given row and column.
  • Recognise row, column, square, zero and identity matrices.
  • Decide when two matrices are equal and find unknown values.

2Study Notes

Matrix. A rectangular array of numbers arranged in rows (horizontal) and columns (vertical), written inside brackets. Each number is an element (or entry). Matrices are named with capital letters: A, B, C.
Order. A matrix with m rows and n columns has order m × n (“m by n”). Rows first, then columns. It has m × n elements. Example: A =
251
037
 has 2 rows and 3 columns, so its order is 2 × 3 and it has 6 elements.
Naming an element. aᵢⱼ is the element in row i and column j. In the matrix A above, a₁₂ = 5 (row 1, column 2) and a₂₃ = 7 (row 2, column 3).
Special matrices. Row matrix: one row (1 × n). Column matrix: one column (m × 1). Square matrix: same number of rows and columns (n × n). Zero matrix O: every element is 0. Identity matrix I: a square matrix with 1 on the main diagonal (top-left to bottom-right) and 0 elsewhere: I =
10
01
 for 2 × 2.
Equal matrices. Two matrices are equal if they have the same order and every pair of matching elements is equal.
Transpose (extra). The transpose Aᵀ swaps rows and columns. If A is 2 × 3 then Aᵀ is 3 × 2.

  1. Count the rows. 2 rows.
  2. Count the columns. 3 columns.
  3. Order = rows × columns. 2 × 3.
  4. Number of elements = 2 × 3. 6.

Example 8 (order from a description). A matrix has 3 rows and 4 columns. State its order, the number of elements, and the order of its transpose.
  1. Order: rows × columns. 3 × 4.
  2. Elements. 3 × 4 = 12.
  3. The transpose swaps rows and columns. 4 × 3.
Answer: 3 × 4; 12 elements; transpose 4 × 3.
Common mistakes.
① Writing the order as columns × rows. It is rows first.
② Mixing up aᵢⱼ: i is the row and j is the column.
③ Calling a matrix “equal” when the orders are different.
④ Forgetting that the identity matrix needs 1s on the diagonal, not just any equal numbers.
⑤ Putting the elements in a different order from the table.

3History & Facts

  • Ancient China (about 200 BCE): the “Nine Chapters on the Mathematical Art” solved systems of equations with arrays of numbers.
  • James Joseph Sylvester (1850): introduced the word “matrix”, Latin for “womb”, because a matrix produces determinants.
  • Arthur Cayley (1858): wrote the first full theory of matrices.
  • Today: computer graphics, spreadsheets, search engines and AI all store data in matrices.

5Real-World Applications

  • Spreadsheets: a table of marks with students as rows and subjects as columns is a matrix.
  • Computer graphics: every pixel image and 3D transformation uses matrices.
  • Business: sales by shop and product.
  • Networks: which towns are joined by roads.
  • Science: storing measurements from many sensors.

6IB Links: TOK, International-mindedness & ATL

  • TOK: Is a matrix a number, a table, or an object in its own right? How do new mathematical objects get invented?
  • International-mindedness: arrays of numbers were used in China about 2000 years ago, long before Sylvester and Cayley named them in Europe.
  • ATL: communication (stating the order correctly), thinking (reading the structure of a table).
  • IA ideas: store survey data in a matrix and explore what operations on it mean.
