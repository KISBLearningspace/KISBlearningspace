2Study Notes

Standard form
ax² + bx + c = 0  (a ≠ 0)
Roots are the x-values that satisfy the equation; the graph is a parabola. a > 0 opens up, a < 0 opens down; c is the y-intercept.

Method 1 · Factoring

If (x − p)(x − q) = 0 then x = p or x = q.

Example (factorising). Solve x² + x − 6 = 0.
  1. Check that one side is 0. It is.
  2. Find two numbers with product −6 and sum +1. 3 and −2.
  3. Factorise. (x + 3)(x − 2) = 0.
  4. Zero-product rule. x + 3 = 0 or x − 2 = 0.
Answer: x = −3 or x = 2

Method 2 · Quadratic formula

x = ⟦−b ± √{b² − 4ac}|2a⟧

Discriminant Δ = b² − 4ac: Δ > 0 two real roots · Δ = 0 one repeated root · Δ < 0 no real roots.

Example (formula). Solve 2x² − 3x − 2 = 0.
  1. Identify a, b, c. a = 2, b = −3, c = −2.
  2. Discriminant. Δ = b² − 4ac = 9 − 4(2)(−2) = 9 + 16 = 25. Δ > 0, so two real roots.
  3. Quadratic formula. x = ⟦−b ± √{Δ}|2a⟧ = ⟦3 ± 5|4⟧.
  4. Two roots. x = ⟦8|4⟧ = 2 or x = ⟦−2|4⟧ = −⟦1|2⟧.
Answer: x = 2 or x = −⟦1|2⟧

Method 3 · Completing the square

x² + bx + c = (x + ⟦b|2⟧)² − ⟦b²|4⟧ + c
Example (completing the square). Write y = x² + 4x − 5 in vertex form, then find the vertex and roots.
  1. Half the coefficient of x. Half of 4 is 2.
  2. Complete the square. x² + 4x = (x + 2)² − 4, so y = (x + 2)² − 4 − 5 = (x + 2)² − 9.
  3. Vertex. (−2, −9).
  4. Roots: set y = 0. (x + 2)² = 9, so x + 2 = ±3.
Answer: Vertex (−2, −9); roots x = 1 or x = −5.
Think: ① Why must a ≠ 0? ② Why does Δ < 0 mean the graph never touches the x-axis? ③ How can you find the axis of symmetry from the two roots?

4History & Facts

  • Babylon (about 2000 BCE): clay tablets show problems about areas that lead to quadratic equations, solved by step-by-step rules.
  • Apollonius (about 200 BCE): studied the parabola as a conic section and gave it its name.
  • Brahmagupta (628 CE): gave a general solution and worked with negative numbers.
  • Al-Khwarizmi (about 820 CE): his book Al-jabr explained completing the square; the word “algebra” comes from it.
  • Galileo (early 1600s): showed that thrown objects follow parabolic paths.
  • Word fact: “quadratic” comes from Latin quadratus, meaning “square”, because of the x² term.

6Real-World Applications

  • Sport: the path of a football, basketball or javelin is a parabola.
  • Engineering: satellite dishes and car headlights use parabolic reflectors; the cables of suspension bridges hang in a nearly parabolic curve.
  • Road safety: braking distance grows with the square of speed, so doubling speed roughly quadruples the distance.
  • Business: profit models are often quadratic, and the vertex gives the best price.
Garden problem. The length is 2 m more than the width and the area is 24 m². Find the dimensions.
  1. Define a variable. Let the width be w m. Then the length is w + 2.
  2. Form the equation. Area: w(w + 2) = 24.
  3. Rearrange to = 0. w² + 2w − 24 = 0.
  4. Factorise. (w + 6)(w − 4) = 0, so w = −6 or w = 4.
  5. Reject the impossible value. A width cannot be negative, so w = 4. Length = 4 + 2 = 6.
Answer: Width 4 m, length 6 m (check: 4 × 6 = 24 ✓)

8Classwork & Homework

Classwork

  1. Solve x² − 8x + 15 = 0.
    Answer(x − 3)(x − 5) = 0 → x = 3 or x = 5.
  2. Solve x² + 6x = 0.
    Answerx(x + 6) = 0 → x = 0 or x = −6.
  3. Use the formula to solve x² − 4x − 1 = 0.
    AnswerΔ = 16 + 4 = 20; x = ⟦4 ± √{20}|2⟧ = 2 ± √{5}.
  4. Find the vertex and roots of y = x² − 4x − 5.
    Answery = (x − 2)² − 9; vertex (2, −9); roots x = −1 and x = 5.

Homework

  1. Solve 2x² − 7x + 3 = 0.
    Answer(2x − 1)(x − 3) = 0 → x = ⟦1|2⟧ or x = 3.
  2. Find Δ for x² + 3x + 5 = 0 and describe the roots.
    AnswerΔ = 9 − 20 = −11 < 0: no real roots.
  3. Complete the square: x² − 10x + 7.
    Answer(x − 5)² − 18.
  4. h = −5t² + 15t. Find the maximum height and the landing time.
    AnswerMax at t = 1.5 s: h = 11.25 m. Lands when −5t(t − 3) = 0 → t = 3 s.

11Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] Let f(x) = x² − 4x − 5.
(a) Write down the y-intercept of the graph of f. [1]
(b) Factorise f(x). [2]
(c) Hence write down the solutions of f(x) = 0. [1]
(d) Find the coordinates of the vertex. [2]
Mark scheme(a) A1 (0, −5).
(b) M1 find factors with product −5 and sum −4; A1 (x − 5)(x + 1).
(c) A1 x = 5 or x = −1.
(d) M1 x = ⟦−(−4)|2(1)⟧ = 2; A1 f(2) = 4 − 8 − 5 = −9, vertex (2, −9).
Question 2 [3 marks] The equation kx² − 6x + 3 = 0 has two equal real roots. Find k.
Mark schemeM1 Δ = (−6)² − 4(k)(3); A1 36 − 12k = 0; A1 k = 3.

Paper 2 style (GDC allowed)

Question 3 [8 marks] A ball is thrown. Its height in metres after t seconds is h(t) = −4.9t² + 14t + 1.2.
(a) Write down the initial height. [1]
(b) Find the maximum height and the time it occurs. [2]
(c) Find the time when the ball hits the ground. [2]
(d) Find the times between which the ball is higher than 10 m. [3]
Mark scheme(a) A1 1.2 m.
(b) A1 t = 1.43 s; A1 h = 11.2 m.
(c) M1 set h(t) = 0 (or use the zero tool); A1 t = 2.94 s.
(d) M1 set h(t) = 10 (or intersect with y = 10); A1 t = 0.934 s; A1 t = 1.92 s.

12Project · The Projectile Challenge

Driving question: Can a parabola predict how high a thrown ball goes?

Materials: soft ball, tape measure or metre ruler, phone with slow-motion video, graph paper or a spreadsheet. Work in groups of 3–4 outdoors or in the hall.

  1. Fix the ruler upright beside the throw path; one student throws the ball up and across.
  2. Film in slow motion and pause on frames at equal time steps.
  3. Record time and height in a table (at least 8 points).
  4. Plot the points and draw a smooth curve; read the vertex and the landing time.
  5. Fit h = −5t² + vt + h₀ using Lab B until the curve matches your data.
  6. Explain differences between your model and your data (air, measuring error).
