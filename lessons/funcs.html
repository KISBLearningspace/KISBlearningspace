2Study Notes

A function is a relation in which each input x has exactly one output y. Written f(x) or f: x ↦ f(x).
  • Domain: all possible inputs (x). Range: all possible outputs (y).
  • Vertical line test: if any vertical line meets the graph more than once, it is not a function.
  • Represent functions with a table, a mapping diagram, an equation or a graph.
Example 1. Decide whether each table is a function: (a) (−2, 5), (0, 1), (3, 4); (b) (1, 2), (1, −3), (2, 4).
  1. Use the definition. A relation is a function if every input x has exactly one output y.
  2. (a) Check each x-value. The inputs −2, 0 and 3 are all different, so each has one output.
  3. (b) Check each x-value. The input x = 1 appears twice with different outputs (2 and −3).
Answer: (a) is a function; (b) is not a function.
Example 2. f(x) = x² − 4. Find f(−2).
  1. Replace x by −2. f(−2) = (−2)² − 4.
  2. Square first (use brackets for negatives). (−2)² = 4.
  3. Subtract. 4 − 4 = 0.
Answer: f(−2) = 0
Example 3. Find the domain and range of (a) y = 2x − 1, (b) y = x² + 1, (c) y = √{x − 2}, (d) y = ⟦1|x − 3⟧ (domain only).
  1. Domain = allowed inputs; range = possible outputs. Look for division by zero and square roots of negatives.
  2. (a) A straight line accepts any x and reaches every y. Domain ℝ, range ℝ.
  3. (b) Any x is allowed. Since x² ≥ 0, we get y ≥ 1. Domain ℝ, range y ≥ 1.
  4. (c) The inside of the root must be at least 0: x − 2 ≥ 0, so x ≥ 2. A square root is never negative, so y ≥ 0.
  5. (d) The denominator cannot be 0: x − 3 ≠ 0, so x ≠ 3.
Answer: (a) ℝ, ℝ (b) ℝ, y ≥ 1 (c) x ≥ 2, y ≥ 0 (d) x ≠ 3
Example 4 (restricted domain). f(x) = 2x + 1 for −3 ≤ x ≤ 2. Find the range.
  1. The function is increasing. The gradient 2 is positive, so the smallest output is at the smallest x and the largest output at the largest x.
  2. Evaluate at the ends. f(−3) = 2(−3) + 1 = −5 and f(2) = 2(2) + 1 = 5.
  3. Write the range. All values between these two.
Answer: −5 ≤ y ≤ 5
Think: Is the circle x² + y² = 4 a function? Which part of it is a function if we only take the top half?

3History & Facts

  • Gottfried Leibniz (1673): first used the word “function”.
  • Leonhard Euler (1730s): introduced the notation f(x).
  • Peter Dirichlet (1837): gave the modern definition of a function as a rule linking inputs to outputs.
