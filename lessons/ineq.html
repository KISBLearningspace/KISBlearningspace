2Study Notes

An inequality has a range of solutions. Symbols: > greater than, < less than, ≥ greater than or equal to, ≤ less than or equal to.
  • Add or subtract the same number on both sides: the sign stays.
  • Multiply or divide by a positive number: the sign stays.
  • Multiply or divide by a negative number: reverse the sign.
InequalityInterval notationNumber line
x > 3(3, ∞)open circle, arrow right
x ≥ 3[3, ∞)closed circle, arrow right
x < 1(−∞, 1)open circle, arrow left
x ≤ 1(−∞, 1]closed circle, arrow left

Set notation: {x ∈ ℝ | x > 3}. IB papers may also write intervals as ]3, ∞[.

Example 1. Solve (a) 2x + 4 > 10, (b) −3x ≤ 12, (c) 5(x − 2) < 15.
  1. (a) Treat it like an equation. Subtract 4 from both sides: 2x > 6. Divide by 2: x > 3.
  2. (b) Dividing by a negative number reverses the inequality. −3x ≤ 12. Divide both sides by −3 and flip the sign: x ≥ −4.
  3. (c) Expand the bracket first. 5x − 10 < 15. Add 10: 5x < 25. Divide by 5: x < 5.
  4. Check a value. For (a) try x = 4: 2(4) + 4 = 12 > 10 ✓
Answer: (a) x > 3 (b) x ≥ −4 (c) x < 5
Example 2 (quadratic inequality, SL 2.7). Solve x² − x − 6 < 0.
  1. Factorise. x² − x − 6 = (x − 3)(x + 2).
  2. Find the roots. (x − 3)(x + 2) = 0 gives x = 3 and x = −2.
  3. Sketch the parabola. The coefficient of x² is positive, so the parabola opens upwards and crosses the x-axis at −2 and 3.
  4. Read the region you need. We want x² − x − 6 < 0, that is, where the graph is below the x-axis. That is between the roots.
Answer: −2 < x < 3
Think: Check −3x ≤ 12 with x = 0 and x = −5. Which is a solution? How does this confirm the flipped sign?

3History & Facts

  • Thomas Harriot (1631): introduced the symbols > and < in a book published after his death.
  • Pierre Bouguer (1734): introduced the ≥ and ≤ type of symbols.
  • Fact: linear programming uses systems of inequalities to find the best use of limited resources.

5Real-World Applications

  • Budgets: spend at most $200: 12x ≤ 200.
  • Speed limits and safety: v ≤ 80.
  • Medicine: a safe dose lies between a minimum and a maximum.
  • Business: revenue must exceed cost for a profit.

    Answer3x + 3 ≥ 2x + 5 → x ≥ 2.
