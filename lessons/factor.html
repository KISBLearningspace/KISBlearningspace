Syllabus: Mathematics: analysis and approaches · Topic 2 Functions · algebra skill that supports SL 2.6 and SL 2.7 (writing a quadratic in factored form to find x-intercepts and solve equations). HL students study the same content.

Guiding questions

  • How is factorising related to expanding?
  • Which method should I try first for a given expression?
  • How does factorising help us solve equations and find x-intercepts?

Learning outcomes

  • Take out a common factor.
  • Use the difference of two squares and perfect squares.
  • Factorise quadratics x² + bx + c and ax² + bx + c.
  • Use factorising to solve equations.

2Study Notes

  • Common factor: ab + ac = a(b + c).   6x² + 9x = 3x(2x + 3)
  • Difference of two squares: a² − b² = (a − b)(a + b).   x² − 16 = (x − 4)(x + 4)
  • Perfect squares: a² ± 2ab + b² = (a ± b)².   x² + 6x + 9 = (x + 3)²
  • Trinomial (a = 1): x² + bx + c = (x + m)(x + n) where m + n = b and mn = c
Example 1. Factorise x² + 5x + 6.
  1. Look for two numbers. They must multiply to the constant term, 6, and add to the coefficient of x, 5.
  2. List the factor pairs of 6. 1 × 6 (sum 7), 2 × 3 (sum 5). The pair 2 and 3 works.
  3. Write the factors. x² + 5x + 6 = (x + 2)(x + 3).
  4. Check by expanding. (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6 ✓
Answer: (x + 2)(x + 3)
Example 2. Factorise 2x² + 5x − 3.
  1. The coefficient of x² is not 1, so multiply a × c. a × c = 2 × (−3) = −6.
  2. Find two numbers with product −6 and sum 5. 6 and −1 (6 × (−1) = −6 and 6 + (−1) = 5).
  3. Split the middle term. 2x² + 5x − 3 = 2x² + 6x − x − 3.
  4. Factorise in pairs. 2x(x + 3) − 1(x + 3). The bracket (x + 3) is common to both parts.
  5. Take out the common bracket. (x + 3)(2x − 1).
Answer: (2x − 1)(x + 3)
Example 3. Solve x² − 3x − 10 = 0.
  1. Factorise the left side. Find two numbers with product −10 and sum −3: −5 and 2. So x² − 3x − 10 = (x − 5)(x + 2).
  2. Use the zero-product rule. If a product is 0, one factor must be 0: (x − 5)(x + 2) = 0 gives x − 5 = 0 or x + 2 = 0.
  3. Solve each equation. x = 5 or x = −2.
  4. Check one root. (5)² − 3(5) − 10 = 25 − 15 − 10 = 0 ✓
Answer: x = 5 or x = −2

Always look for a common factor first. Check by expanding.

Think: Why does factorising a quadratic help us find where its graph crosses the x-axis?

3History & Facts

  • Euclid’s Elements (about 300 BCE): Book II proves identities such as (a + b)² using areas of rectangles and squares.
  • Al-Khwarizmi (about 820 CE): explained algebra with geometric areas.
  • Area model: a rectangle of height h and width (a + b) has area h(a + b) = ha + hb.

5Real-World Applications

  • Geometry: finding the dimensions of a rectangle from its area.
  • Physics: finding when a projectile is at ground level.
  • Engineering: simplifying formulas before using them.
