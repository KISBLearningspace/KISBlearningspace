2Study Notes

Sine rule. In triangle ABC with the usual labelling (side a is opposite angle A):
⟦a|sin A⟧ = ⟦b|sin B⟧ = ⟦c|sin C⟧
To find a side use the form ⟦a|sin A⟧ = ⟦b|sin B⟧ (unknown on top). To find an angle use ⟦sin A|a⟧ = ⟦sin B|b⟧ (unknown on top). Angles in a triangle add to 180°.
When to use it. You know a side and the angle opposite it (a “pair”), and one more side or angle. This is AAS, ASA or SSA. If you know two sides and the included angle, or all three sides, use the cosine rule (next lesson).
Example 1 (AAS). In triangle ABC, A = 40°, B = 65° and a = 8. Find C, b and c.
  1. Find the third angle. C = 180° − 40° − 65° = 75°.
  2. Write the sine rule. ⟦a|sin A⟧ = ⟦b|sin B⟧ = ⟦c|sin C⟧.
  3. Find b. b = ⟦a sin B|sin A⟧ = ⟦8 sin 65°|sin 40°⟧ ≈ 11.3.
  4. Find c. c = ⟦a sin C|sin A⟧ = ⟦8 sin 75°|sin 40°⟧ ≈ 12.0.
Answer: C = 75°, b ≈ 11.3, c ≈ 12.0
The ambiguous case (SSA). Given angle A, side a (opposite A) and side b, let h = b sin A be the height.
• a < h: no triangle.
• a = h: one right-angled triangle.
• h < a < b: two triangles.
• a ≥ b: one triangle.
The two answers for B are B and 180° − B, because sin B has two angle solutions between 0° and 180°.
Example 2 (two triangles). A = 35°, a = 9, b = 12. Find B and C.
  1. Sine rule for the angle. sin B = ⟦b sin A|a⟧ = ⟦12 sin 35°|9⟧ ≈ 0.7647.
  2. Two angles have this sine. B ≈ 49.9° (calculator) or B ≈ 180° − 49.9° = 130.1°.
  3. Test whether each fits. The angles must total less than 180°. With A = 35°: 35° + 49.9° < 180° ✓ and 35° + 130.1° = 165.1° < 180° ✓. Both are possible.
  4. Find C in each case. C = 180° − 35° − 49.9° = 95.1°, or C = 180° − 35° − 130.1° = 14.9°.
Answer: Two triangles: B ≈ 49.9°, C ≈ 95.1° or B ≈ 130.1°, C ≈ 14.9°.
Example 3 (no triangle). A = 50°, a = 5, b = 10. Find B.
  1. Sine rule. sin B = ⟦b sin A|a⟧ = ⟦10 sin 50°|5⟧ ≈ 1.53.
  2. Interpret. The sine of an angle cannot be more than 1.
  3. Check with a height. The height from C is h = 10 sin 50° ≈ 7.66, which is more than a = 5, so side a is too short to reach the base.
Answer: There is no triangle.
Example 4 (river width). Posts A and B are 50 m apart on one bank. A tree C is on the other bank, with ∠CAB = 62° and ∠ABC = 48°. Find the width of the river.
  1. Find the angle at C. C = 180° − 62° − 48° = 70°.
  2. Use the sine rule for AC (opposite angle B). AC = ⟦50 sin 48°|sin 70°⟧ ≈ 39.5 m.
  3. The width is the perpendicular distance from C to AB. Use the right-angled triangle at A: width = AC sin 62° = 39.5 sin 62° ≈ 34.9 m.
Answer: The river is about 34.9 m wide.
Why the ambiguous case happens: sin 50° = sin 130°. A calculator gives only the acute angle, so always ask: could the obtuse angle also work? Check that the angles add to less than 180°.
Think: ① Why can a triangle have at most one obtuse angle, and how does that help in the ambiguous case? ② For SSA with a ≥ b, why does the obtuse option fail? ③ Prove the sine rule by splitting an acute triangle with its height.

3History & Facts

  • Nasir al-Din al-Tusi (1200s): gave one of the first clear statements of the sine rule for plane triangles.
  • Al-Biruni and Islamic astronomers: used the rule to compute distances between cities and to find the direction of prayer.
  • Great Trigonometrical Survey of India (1800s): measured a chain of triangles from the coast to the Himalayas and calculated the height of Mount Everest.
  • Fact: triangulation is still the basis of surveying, and the same idea sits behind GPS.

5Real-World Applications

  • Surveying: distance across rivers, valleys or to an inaccessible peak using a baseline and two angles.
  • Navigation: bearings from two lighthouses fix a ship’s position.
  • Astronomy: the distance to the Moon or a planet from angles measured at two places.
  • Engineering: forces in a truss or crane where members meet at non-right angles.
  • Search and rescue: locating a signal from two direction readings.

7Classwork & Homework

Classwork

  1. In triangle ABC, A = 52°, B = 71°, a = 10. Find b.
    Answerb = ⟦10 sin 71°|sin 52°⟧ ≈ 12.0.
  2. In triangle PQR, p = 8, q = 11, P = 30°. Find angle Q (acute).
    Answersin Q = ⟦11 sin 30°|8⟧ = 0.6875, Q ≈ 43.4°.
  3. For the same triangle, is there a second possible value of Q? If so, find the third angle in each case.
    AnswerQ = 136.6°; 30° + 136.6° = 166.6° < 180°, so yes. R = 106.6° (Q acute) or 13.4° (Q obtuse).
  4. A = 50°, a = 5, b = 10. How many triangles are possible? Explain.
    Answerh = 10 sin 50° ≈ 7.66 > 5, so none.

Homework

  1. In triangle ABC, A = 30°, B = 45°, a = 6. Find b in exact form.
    Answerb = ⟦6 sin 45°|sin 30°⟧ = 6√{2}.
  2. A = 40°, a = 7, b = 10. Find both possible values of B.
    Answersin B = 0.918; B = 66.7° or 113.3°.
  3. Find the third side c in each case of HW 2.
    AnswerTriangle 1: C = 73.3°, c = ⟦7 sin 73.3°|sin 40°⟧ ≈ 10.4. Triangle 2: C = 26.7°, c ≈ 4.89.
  4. Two points A and B are 80 m apart. A tower T has ∠TAB = 55° and ∠TBA = 65°. Find AT.
    AnswerT = 60°; AT = ⟦80 sin 65°|sin 60°⟧ ≈ 83.7 m.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [5 marks] In triangle ABC, A = 45°, B = 60° and a = √{6}. Find the exact value of b.
Mark schemeM1 ⟦√{6}|sin 45°⟧ = ⟦b|sin 60°⟧; A1 sin 45° = ⟦√{2}|2⟧ and sin 60° = ⟦√{3}|2⟧; M1 b = ⟦√{6} × √{3}|√{2}⟧; A1 √{18}/√{2}; A1 b = 3.
Question 2 [5 marks] Show that if A = 30°, a = 5 and b = 10, then triangle ABC is right-angled, and find c.
Mark schemeM1 sin B = ⟦10 sin 30°|5⟧; A1 sin B = 1; R1 B = 90°; M1 C = 60°; A1 c = 5√{3} (or ⟦5 sin 60°|sin 30°⟧ = 5√{3}).

Paper 2 style (GDC allowed)

Question 3 [8 marks] In triangle ABC, A = 40°, a = 7 and b = 10.
(a) Show that there are two possible triangles. [3]
(b) Find both possible values of angle B. [2]
(c) Find the length of side c in each case. [3]
Mark scheme(a) M1 h = 10 sin 40° = 6.43; A1 h < a; R1 a < b, so two triangles (or sin B = 0.918 < 1 with both angles valid).
(b) A1 66.7°; A1 113.3°.
(c) M1 C = 73.3° or 26.7°; A1 c = 10.4; A1 c = 4.89.
