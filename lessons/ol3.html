1IB Syllabus Link & Learning Outcomes

Purpose: Olympiad extension for Grades 7–12 and IB students. Links to Number and algebra (expanding, factorising and identities). All questions are original and written in the style of olympiad papers.
Levels
[Level 1] Grades 4–6 · [Level 2] Grades 7–9 · [Level 3] Grades 10–12. Previous lesson: Patterns, Sequences and Number Puzzles.

Guiding questions

  • When can we answer without finding the unknowns?
  • Which identities turn a hard expression into a known value?
  • How can factorising help to solve equations in whole numbers?

Learning outcomes

  • Rewrite an expression so that a given sum or product can be substituted.
  • Use (a + b)², (a − b)² and a² − b² as tools.
  • Use x + 1/x = s to find powers such as x² + 1/x² and x³ + 1/x³.
  • Solve equal-ratio problems with a constant k.
  • Factorise an integer equation and list the factor pairs.

2Study Notes

Trick 1: Do not solve. Substitute the whole. If you are given m + n = 3, do not find m and n. Rewrite the expression so that (m + n) appears: 2m² + 4mn + 2n² = 2(m + n)² = 18.
Trick 2: Key identities. (a + b)² = a² + 2ab + b², (a − b)² = a² − 2ab + b², a² − b² = (a − b)(a + b), a² + b² = (a + b)² − 2ab.
Trick 3: Reciprocal pairs. If x + ⟦1|x⟧ = s then x² + ⟦1|x²⟧ = s² − 2 and x³ + ⟦1|x³⟧ = s³ − 3s.
Trick 4: Equal ratios. If ⟦a|2⟧ = ⟦b|3⟧ = ⟦c|4⟧ = k, write a = 2k, b = 3k, c = 4k. Then k cancels.
Trick 5: Factor integer equations. Move everything to one side and factorise. The product of two integers is fixed, so list the factor pairs. Check that each pair gives positive whole numbers.
Trick 6: Sum of coefficients. The sum of the coefficients of a polynomial P(x) is P(1).

Example 1 [Level 1]. x + y = 8 and xy = 15. Find x² + y².
  1. Use x² + y² = (x + y)² − 2xy. 64 − 30
Answer: 34
Example 2 [Level 2] (substitute the whole). m + n = 5. Find 3m² + 6mn + 3n² − 10.
  1. Factor out 3. 3(m² + 2mn + n²) = 3(m + n)²
  2. Substitute. 3 × 25 − 10 = 65
Answer: 65
Example 3 [Level 2] (reciprocals). x + ⟦1|x⟧ = 5. Find x² + ⟦1|x²⟧ and x³ + ⟦1|x³⟧.
  1. Square both sides: x² + 2 + ⟦1|x²⟧ = 25. x² + ⟦1|x²⟧ = 23
  2. Use x³ + ⟦1|x³⟧ = s³ − 3s with s = 5. 125 − 15 = 110
Answer: 23 and 110
Example 4 [Level 2] (equal ratios). ⟦a|2⟧ = ⟦b|3⟧ = ⟦c|4⟧. Find ⟦a + b + c|c⟧.
  1. Let each ratio be k: a = 2k, b = 3k, c = 4k. a + b + c = 9k
  2. Divide by c = 4k. ⟦9|4⟧
Answer: ⟦9|4⟧
Example 5 [Level 3] (squares of squares). √{2^x} + √{2^(−x)} = 3. Find 4^x + 4^(−x).
  1. Square both sides: 2^x + 2 + 2^(−x) = 9. 2^x + 2^(−x) = 7
  2. Square again: 4^x + 2 + 4^(−x) = 49. 4^x + 4^(−x) = 47
Answer: 47
Example 6 [Level 3] (integer factors). How many pairs of positive integers (a, b) satisfy a² − b² = 45?
  1. Factorise: (a − b)(a + b) = 45. Factor pairs (1, 45), (3, 15), (5, 9)
  2. Both factors are odd, so a = (sum) ÷ 2 and b = (difference) ÷ 2 are whole. (23, 22), (9, 6), (7, 2)
Answer: 3 pairs
Example 7 [Level 2] (sum of coefficients). Find the sum of the coefficients of (2x + 1)^5.
  1. Put x = 1. 3⁵ = 243
Answer: 243
Common mistakes.
① Forgetting the −2 in x² + ⟦1|x²⟧ = s² − 2.
② Solving for x and y when the identity is much faster.
③ Not checking that factor pairs give positive whole numbers (parity!).
④ Taking only one of the two orders of a factor pair (a − b is always the smaller factor).
⑤ Putting x = 0 instead of x = 1 for the sum of coefficients.

3History & Facts

  • Diophantus of Alexandria (about 250 CE): studied equations for whole numbers, now called Diophantine equations.
  • Al-Khwarizmi (about 820 CE): his book on balancing and completing gave algebra its name.
  • Pierre de Fermat (1600s): famous problems about integer equations led to deep mathematics.

5Real-World Applications

  • Computer science: hashing and coding use identities to simplify checks.
  • Physics: simplifying expressions with a fixed total (energy, momentum).
  • Cryptography: factoring numbers is the basis of many security methods.
  • Engineering: substitute known sums instead of solving big systems.
  • Economics: ratios and proportions in budgets.

10Exam-style Questions

Original questions in the style of a maths olympiad. Section A = 3 marks, Section B = 4 marks, Section C = 6 marks (write the numerical answer). Open “Solution” only after trying.

Section A

Question 1 [3 marks] If a + b = 6 and ab = 7, then a² + b² = (A) 20 (B) 22 (C) 24 (D) 26 (E) 28
Solution(B) 22. a² + b² = (a + b)² − 2ab = 36 − 14.
Question 2 [3 marks] If m + n = 4, then 3m² + 6mn + 3n² = (A) 36 (B) 40 (C) 44 (D) 48 (E) 52
Solution(D) 48 = 3(m + n)² = 3 × 16.

Section B

Question 3 [4 marks] If x + ⟦1|x⟧ = 6, then x⁴ + ⟦1|x⁴⟧ = (A) 1148 (B) 1150 (C) 1152 (D) 1154 (E) 1156
Solution(D) 1154. x² + ⟦1|x²⟧ = 36 − 2 = 34. Then x⁴ + ⟦1|x⁴⟧ = 34² − 2 = 1154.

Section C

Question 4 [6 marks] Positive integers a and b satisfy a² − b² = 105. Find the sum of all possible values of a.
Solution96. (a − b)(a + b) = 105 with factor pairs (1, 105), (3, 35), (5, 21), (7, 15). All pairs are odd, so a = 53, 19, 13, 11. Sum = 96.
