2Study Notes

Trick 1: AM-GM. For positive numbers a and b: ⟦a + b|2⟧ ≥ √{ab}, with equality only when a = b. For three numbers: ⟦a + b + c|3⟧ ≥ ∛(abc). “Arithmetic mean ≥ geometric mean.”
Trick 2: Sum and product. If the sum is fixed, the product is largest when the numbers are equal. If the product is fixed, the sum is smallest when the numbers are equal.
Trick 3: Squares are never negative. (a − b)² ≥ 0 gives a² + b² ≥ 2ab. Also x + ⟦1|x⟧ ≥ 2 for x > 0.
Trick 4: Complete the square. x² − 6x + 13 = (x − 3)² + 4 ≥ 4. The minimum is 4 when x = 3.
Trick 5: Pair the terms. In ⟦y + z|x⟧ + ⟦z + x|y⟧ + ⟦x + y|z⟧ group ⟦x|y⟧ + ⟦y|x⟧ ≥ 2 three times to get ≥ 6.
Always check equality. The minimum is only correct if the equality case can happen with the numbers allowed (positive, whole, …).

Example 1 [Level 1]. Two numbers add to 20. What is their largest product?
  1. Make the numbers equal. 10 × 10 = 100
  2. Compare 9 × 11 = 99 and 8 × 12 = 96. The product falls as the numbers move apart
Answer: 100
Example 2 [Level 2] (AM-GM). For x > 0, find the minimum value of x + ⟦16|x⟧.
  1. AM-GM: x + ⟦16|x⟧ ≥ 2√{x × ⟦16|x⟧}. 2 × 4 = 8
  2. Equality when x = ⟦16|x⟧. x = 4
Answer: 8
Example 3 [Level 2] (complete the square). Find the minimum value of x² − 6x + 13.
  1. Complete the square. (x − 3)² + 4
  2. A square is at least 0. Minimum 4 when x = 3
Answer: 4
Example 4 [Level 3]. a, b > 0 and a + b = 12. Find the minimum value of (1 + ⟦1|a⟧)(1 + ⟦1|b⟧).
  1. Expand. 1 + ⟦1|a⟧ + ⟦1|b⟧ + ⟦1|ab⟧ = 1 + ⟦a + b + 1|ab⟧ = 1 + ⟦13|ab⟧
  2. Smallest when ab is largest: a = b = 6, ab = 36. 1 + ⟦13|36⟧
Answer: ⟦49|36⟧
Example 5 [Level 3] (pairing). x, y, z > 0. Find the minimum of ⟦y + z|x⟧ + ⟦z + x|y⟧ + ⟦x + y|z⟧.
  1. Split: (⟦y|x⟧ + ⟦x|y⟧) + (⟦z|x⟧ + ⟦x|z⟧) + (⟦z|y⟧ + ⟦y|z⟧). Each bracket is ≥ 2
  2. Equality when x = y = z. 6
Answer: 6
Example 6 [Level 3] (three numbers). a, b, c > 0 and a + b + c = 12. Find the largest value of abc.
  1. Make the numbers equal. a = b = c = 4
  2. Product. 4 × 4 × 4 = 64
Answer: 64
Example 7 [Level 2] (whole numbers). Integers x and y add to 15. Find the largest product xy.
  1. x and y cannot be equal (15 is odd). Use the closest: 7 and 8. 56
Answer: 56
Common mistakes.
① Using AM-GM with negative numbers (it needs positive numbers).
② Forgetting to check that equality can happen (for whole numbers the equal case may be impossible).
③ Mixing up “fixed sum” and “fixed product”.
④ Giving the value of x instead of the minimum value (or the other way round).
⑤ Not simplifying before applying AM-GM.

3History & Facts

  • Euclid: showed in Greek geometry that among rectangles with a given perimeter the square has the greatest area.
  • Cauchy (1821): gave a clear proof of the AM-GM inequality.
  • Today: optimisation underlies engineering design, machine learning and economics.

5Real-World Applications

  • Packaging: the cheapest box for a given volume.
  • Farming: the largest field for a fixed length of fence.
  • Business: balancing two costs to find the lowest total.
  • Engineering: the strongest beam shape for a fixed amount of material.
  • Sports: the best angle or speed in a throw.

10Exam-style Questions

Original questions in the style of a maths olympiad. Section A = 3 marks, Section B = 4 marks, Section C = 6 marks (write the numerical answer). Open “Solution” only after trying.

Section A

Question 1 [3 marks] a, b > 0 and a + b = 14. The largest value of ab is (A) 42 (B) 45 (C) 48 (D) 49 (E) 52
Solution(D) 49 at a = b = 7.
Question 2 [3 marks] The minimum value of x² − 10x + 30 is (A) 3 (B) 4 (C) 5 (D) 6 (E) 7
Solution(C) 5. (x − 5)² + 5.

Section B

Question 3 [4 marks] For x > 0, the minimum value of 4x + ⟦9|x⟧ is (A) 10 (B) 11 (C) 12 (D) 13 (E) 14
Solution(C) 12. AM-GM gives 4x + ⟦9|x⟧ ≥ 2√{36} = 12, with equality when 4x = ⟦9|x⟧, that is x = ⟦3|2⟧.

Section C

Question 4 [6 marks] a, b, c are positive with abc = 64. Find the minimum value of a + b + c.
Solution12. By AM-GM, ⟦a + b + c|3⟧ ≥ ∛(abc) = 4, with equality at a = b = c = 4.
