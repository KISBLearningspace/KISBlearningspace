2Study Notes

Vertex form
f(x) = a(x − h)² + k
The vertex is (h, k), the axis of symmetry is x = h. If a > 0 the parabola opens upward and k is the minimum value; if a < 0 it opens downward and k is the maximum value.
FormEquationWhat you read directly
Standardf(x) = ax² + bx + cy-intercept c; axis x = −⟦b|2a⟧
Factoredf(x) = a(x − p)(x − q)zeros p and q
Vertexf(x) = a(x − h)² + kvertex (h, k); maximum or minimum k
Link to transformations. The graph of f(x) = a(x − h)² + k comes from y = x² by a vertical stretch of scale factor a (reflected if a < 0), then a translation of h units right and k units up.
Example 1. f(x) = 2(x − 3)² − 8. Find the vertex, axis, minimum, intercepts and the expanded form.
  1. Read the vertex form a(x − h)² + k. a = 2, h = 3, k = −8. Vertex (3, −8) and axis x = 3.
  2. Minimum or maximum? a = 2 > 0, so the parabola opens up and the minimum value is −8.
  3. y-intercept: put x = 0. f(0) = 2(−3)² − 8 = 18 − 8 = 10.
  4. Zeros: put f(x) = 0. 2(x − 3)² = 8, so (x − 3)² = 4, so x − 3 = ±2, giving x = 1 or x = 5.
  5. Expand. 2(x² − 6x + 9) − 8 = 2x² − 12x + 18 − 8 = 2x² − 12x + 10.
Answer: Vertex (3, −8); zeros 1 and 5; y-intercept 10; f(x) = 2x² − 12x + 10.
Example 2 (find the equation). The vertex is (−2, 5) and the graph passes through (0, −3). Find f(x).
  1. Write the vertex form with h = −2 and k = 5. f(x) = a(x + 2)² + 5.
  2. Substitute the point (0, −3) to find a. −3 = a(0 + 2)² + 5 = 4a + 5.
  3. Solve. 4a = −8, so a = −2.
  4. Write the answer and check. f(x) = −2(x + 2)² + 5. Check: f(0) = −2(4) + 5 = −3 ✓
Answer: f(x) = −2(x + 2)² + 5
Example 3 (from a graph). The vertex is (1, −4) and the graph passes through (3, 0). Find f(x).
  1. Vertex form. f(x) = a(x − 1)² − 4.
  2. Substitute (3, 0). 0 = a(3 − 1)² − 4 = 4a − 4.
  3. Solve for a. 4a = 4, so a = 1.
Answer: f(x) = (x − 1)² − 4
Example 4 (from standard form). Write f(x) = x² − 6x + 5 in vertex form.
  1. Axis of symmetry. x = −⟦b|2a⟧ = −⟦−6|2⟧ = 3.
  2. y-coordinate of the vertex. f(3) = 9 − 18 + 5 = −4. Vertex (3, −4).
  3. Write the vertex form with a = 1. f(x) = (x − 3)² − 4.
Answer: f(x) = (x − 3)² − 4 (the next lesson shows how to get this by completing the square).
Example 5 (modelling). A ball’s height is h(t) = −5(t − 2)² + 22 metres. Find the maximum height and when the ball lands.
  1. Read the vertex. The vertex is (2, 22) and a = −5 < 0, so this is a maximum: 22 m at t = 2 s.
  2. The ball lands when h = 0. −5(t − 2)² + 22 = 0.
  3. Solve. (t − 2)² = ⟦22|5⟧ = 4.4, so t − 2 = ±√{4.4}.
  4. Choose the sensible root. t ≥ 0, so t = 2 + √{4.4} ≈ 4.10 (the other root is negative).
Answer: Maximum 22 m at 2 s; lands after about 4.10 s.
Symmetry. Points at the same distance from the axis x = h have the same y-value. So if (x₁, y) and (x₂, y) are on the graph, then h = ⟦x₁ + x₂|2⟧.

3History & Facts

  • Apollonius of Perga (about 200 BCE): named the parabola, hyperbola and ellipse in his work on conic sections.
  • Galileo Galilei (early 1600s): showed that a projectile (without air resistance) follows a parabolic path.
  • Babylonian mathematicians (about 2000 BCE): solved quadratic problems about area using methods equivalent to completing the square.
  • Fact: a parabolic mirror sends parallel rays to a single point (the focus). This is why satellite dishes and car headlights have a parabolic shape.

5Real-World Applications

  • Sport: the path of a basketball, football or golf ball is a parabola, and its vertex is the highest point.
  • Engineering: parabolic arches, suspension-bridge cables and satellite dishes use the shape of a parabola.
  • Business: profit models of the form P = −ax² + bx − c have a maximum at the vertex, which gives the best price.
  • Fountains and water jets: the arc of water is a parabola, so designers choose the vertex height and width.
  • Safety: braking distance grows with the square of speed, a quadratic relationship.

7Classwork & Homework

Classwork

  1. State the vertex and the axis of symmetry of y = (x − 5)² + 2.
    AnswerVertex (5, 2); axis x = 5.
  2. Does y = −3(x + 1)² − 4 have a maximum or a minimum? State its value.
    Answera = −3 < 0, so the graph opens downward and there is a maximum value of −4.
  3. Write y = (x − 2)² − 9 in the form y = x² + bx + c.
    Answery = x² − 4x + 4 − 9 = x² − 4x − 5.
  4. Find the y-intercept and the zeros of y = (x − 2)² − 9.
    Answery-intercept −5. Zeros: (x − 2)² = 9, so x = 5 or x = −1.

Homework

  1. Find the equation of the parabola with vertex (3, −1) that passes through (5, 7).
    Answer7 = a(2)² − 1, so a = 2: y = 2(x − 3)² − 1.
  2. For f(x) = −2(x + 1)² + 8 find the vertex, the y-intercept and the zeros.
    AnswerVertex (−1, 8). y-intercept: −2 + 8 = 6. Zeros: (x + 1)² = 4, so x = 1 or x = −3.
  3. Show that −x² + 4x − 1 = −(x − 2)² + 3 and state the vertex.
    Answer−(x² − 4x + 4) + 3 = −x² + 4x − 1. Vertex (2, 3).
  4. A parabola has axis of symmetry x = 2, a maximum value of 5 and passes through (0, 1). Find its equation.
    Answery = a(x − 2)² + 5; 1 = 4a + 5, so a = −1: y = −(x − 2)² + 5.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] Let f(x) = 2(x − 3)² − 8.
(a) Write down the coordinates of the vertex of the graph of f. [1]
(b) Find the y-intercept. [2]
(c) Find the zeros of f. [3]
Mark scheme(a) A1 (3, −8).
(b) M1 f(0) = 2(9) − 8; A1 10.
(c) M1 2(x − 3)² = 8, so (x − 3)² = 4; M1 x − 3 = ±2; A1 x = 1 and x = 5.
Question 2 [6 marks] A parabola has its vertex at (−2, 5) and passes through the point (0, −3).
(a) Find the equation in the form y = a(x − h)² + k. [3]
(b) Write the equation in the form y = ax² + bx + c. [2]
(c) Write down the range of the function. [1]
Mark scheme(a) A1 h = −2, k = 5; M1 −3 = a(2)² + 5; A1 y = −2(x + 2)² + 5.
(b) M1 −2(x² + 4x + 4) + 5; A1 y = −2x² − 8x − 3.
(c) A1 y ≤ 5.

Paper 2 style (GDC allowed)

Question 3 [7 marks] A ball is thrown upward. Its height above the ground, in metres, t seconds after it is thrown is h(t) = −5(t − 2)² + 22, for t ≥ 0.
(a) Write down the maximum height of the ball and the time at which it occurs. [2]
(b) Find the height from which the ball was thrown. [2]
(c) Find the time when the ball hits the ground, giving your answer to 3 significant figures. [3]
Mark scheme(a) A1 22 m; A1 t = 2 s.
(b) M1 h(0) = −5(4) + 22; A1 2 m.
(c) M1 −5(t − 2)² + 22 = 0, so (t − 2)² = 4.4; M1 t = 2 ± √{4.4}, reject the negative root since t ≥ 0; A1 t = 4.10 s.
