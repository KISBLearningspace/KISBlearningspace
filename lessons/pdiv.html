Polynomial Division and the Remainder Theorem

KISB Diploma Programme · Mathematics: analysis and approaches · AHL 2.12 (HL) · extension for SL · notes · lab · practice · exam-style questions · IA ideas

1IB Syllabus Link & Learning Outcomes

Syllabus: Mathematics: analysis and approaches · AHL 2.12 (Topic 2 Functions, HL only: polynomial functions; the remainder theorem; division of polynomials). SL students can use this lesson as an extension. It builds on factorising (SL 2.6, 2.7) and on function notation (SL 2.2).

Guiding questions

  • Can we divide polynomials in the same way as whole numbers?
  • How can we find a remainder without doing any division?
  • What does a zero remainder tell us about the graph?

Learning outcomes

  • Divide a polynomial by a linear or quadratic divisor using long division and synthetic division.
  • Write P(x) = D(x)Q(x) + R(x) and identify the quotient and the remainder.
  • State and use the remainder theorem: the remainder on division by (x − c) is P(c).
  • Handle divisors of the form (ax − b).
  • Use the remainder theorem to find unknown coefficients.

2Study Notes

Polynomial of degree n: P(x) = aₙxⁿ + … + a₁x + a₀, aₙ ≠ 0.
Division statement
P(x) = D(x) · Q(x) + R(x)
(dividend = divisor × quotient + remainder), where the degree of R is less than the degree of D.
Example 1 (long division). Divide P(x) = 2x³ − 3x² + x + 5 by (x − 2).
  1. Divide the leading terms. 2x³ ÷ x = 2x². Write 2x² in the quotient.
  2. Multiply and subtract. 2x²(x − 2) = 2x³ − 4x². Subtract from P: (2x³ − 3x²) − (2x³ − 4x²) = x². Bring down +x: x² + x + 5.
  3. Repeat. x² ÷ x = x. x(x − 2) = x² − 2x. Subtract: (x² + x) − (x² − 2x) = 3x. Bring down +5: 3x + 5.
  4. Repeat. 3x ÷ x = 3. 3(x − 2) = 3x − 6. Subtract: (3x + 5) − (3x − 6) = 11.
  5. Stop. The remainder 11 has lower degree than (x − 2), so we stop.
Answer: Q(x) = 2x² + x + 3 and R = 11: 2x³ − 3x² + x + 5 = (x − 2)(2x² + x + 3) + 11.
Synthetic division (divisor x − c). Write the coefficients. Bring down the first one. Multiply by c, add to the next coefficient, and repeat. The last number is the remainder; the others are the coefficients of the quotient.

Remainder theorem. When P(x) is divided by (x − c) the remainder is P(c). When P(x) is divided by (ax − b) the remainder is P(⟦b|a⟧).
Why? Put x = c in P(x) = (x − c)Q(x) + R. The bracket becomes 0, so P(c) = R.
Example 2 (remainder theorem). Find the remainder when P(x) = x³ − 4x + 1 is divided by (x + 3).
  1. Remainder theorem. Dividing by (x − c) leaves remainder P(c).
  2. Find c. x + 3 = x − (−3), so c = −3.
  3. Substitute. P(−3) = (−3)³ − 4(−3) + 1 = −27 + 12 + 1 = −14.
Answer: The remainder is −14.
Example 3 (divisor ax − b). Find the remainder when P(x) = 4x³ − 2x² + x − 5 is divided by (2x − 1).
  1. Find where the divisor is zero. 2x − 1 = 0 gives x = ⟦1|2⟧. The remainder is P(⟦1|2⟧).
  2. Substitute. 4(⟦1|8⟧) − 2(⟦1|4⟧) + ⟦1|2⟧ − 5 = ⟦1|2⟧ − ⟦1|2⟧ + ⟦1|2⟧ − 5.
  3. Simplify. ⟦1|2⟧ − 5 = −⟦9|2⟧.
Answer: The remainder is −⟦9|2⟧.
Example 4 (unknown coefficient). P(x) = x³ + kx² − 2x + 4 has remainder 6 when divided by (x − 1). Find k.
  1. Use the remainder theorem with c = 1. P(1) = 6.
  2. Substitute x = 1. 1 + k − 2 + 4 = k + 3.
  3. Solve. k + 3 = 6, so k = 3.
Answer: k = 3
Example 5 (quadratic divisor). Divide x³ + 2x² + 3x + 4 by (x² + 1).
  1. Leading terms. x³ ÷ x² = x. Write x in the quotient.
  2. Multiply and subtract. x(x² + 1) = x³ + x. Subtract: (x³ + 2x² + 3x + 4) − (x³ + x) = 2x² + 2x + 4.
  3. Repeat. 2x² ÷ x² = 2. 2(x² + 1) = 2x² + 2. Subtract: (2x² + 2x + 4) − (2x² + 2) = 2x + 2.
  4. Stop. 2x + 2 has degree 1, which is less than the degree of the divisor (2).
  5. Check. (x² + 1)(x + 2) + 2x + 2 = x³ + 2x² + x + 2 + 2x + 2 = x³ + 2x² + 3x + 4 ✓
Answer: Quotient x + 2, remainder 2x + 2.
Special case. If the remainder is 0 then P(c) = 0, so c is a zero of P and (x − c) is a factor of P. (The next lesson develops this: the factor theorem.)

Technology (GDC / Desmos)

Evaluate P(c) with the table or by storing c. Graph y = P(x): the height of the graph at x = c is the remainder on division by (x − c).

3History & Facts

  • Euclid (about 300 BCE): his division algorithm for whole numbers (a = bq + r) is the model for division of polynomials.
  • Qin Jiushao (China, 1247): described a method for evaluating polynomials that is the same as synthetic division. It is now called Horner’s method after William Horner (1819); Paolo Ruffini (1809) published the rule for dividing by (x − c).
  • Étienne Bézout (1700s): the remainder theorem is often linked to his name.
  • Fact: QR codes, CDs and satellite links use polynomial division to detect and repair errors in data.

5Real-World Applications

  • Computing: Horner’s method evaluates a polynomial with the fewest multiplications, which is how many calculators and programs compute it.
  • Error-correcting codes: QR codes, CDs and deep-space radio use polynomial division to repair damaged data.
  • Cryptography: modern encryption and secret-sharing schemes use polynomials over finite sets of numbers.
  • Engineering: control systems analyse polynomial equations whose roots show whether a design is stable.
  • Pure mathematics: dividing out known factors makes a hard equation easier.

7Classwork & Homework

Classwork

  1. Find the remainder when x² + 3x − 4 is divided by (x − 2).
    AnswerP(2) = 4 + 6 − 4 = 6.
  2. Divide x³ + 2x² − 5x − 6 by (x − 2) using synthetic division.
    AnswerCoefficients 1, 2, −5, −6 with c = 2 give sums 1, 4, 3, 0. Q = x² + 4x + 3, R = 0.
  3. Find the remainder when x³ − 4x + 1 is divided by (x + 3).
    AnswerP(−3) = −27 + 12 + 1 = −14.
  4. The remainder when x³ + kx² − 2x + 4 is divided by (x − 1) is 6. Find k.
    AnswerP(1) = k + 3 = 6, so k = 3.

Homework

  1. Find the remainder when 4x³ − 2x² + x − 5 is divided by (2x − 1).
    AnswerP(⟦1|2⟧) = ⟦1|2⟧ − ⟦1|2⟧ + ⟦1|2⟧ − 5 = −⟦9|2⟧.
  2. Divide x³ + 2x² + 3x + 4 by (x² + 1).
    AnswerQuotient x + 2, remainder 2x + 2.
  3. Divide x³ − 5x² + 7x − 2 by (x − 2).
    AnswerSums 1, −3, 1, 0: Q = x² − 3x + 1, R = 0.
  4. Find the remainder when x⁴ − 3x² + 2x − 5 is divided by (x + 1).
    AnswerP(−1) = 1 − 3 − 2 − 5 = −9.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] Let P(x) = 2x³ − 3x² + x + 5.
(a) Find the remainder when P(x) is divided by (x − 2). [2]
(b) Find the quotient Q(x) such that P(x) = (x − 2)Q(x) + R. [3]
(c) State, with a reason, whether (x − 2) is a factor of P(x). [1]
Mark scheme(a) M1 P(2) = 16 − 12 + 2 + 5; A1 11.
(b) M1 division or comparing coefficients; A1 2x²; A1 + x + 3, so Q(x) = 2x² + x + 3.
(c) R1 No, since the remainder is 11 ≠ 0.
Question 2 [6 marks] When P(x) = x³ + kx² − 2x + 4 is divided by (x − 1) the remainder is 6.
(a) Find the value of k. [3]
(b) Find the remainder when P(x) is divided by (x + 1). [3]
Mark scheme(a) M1 P(1); M1 1 + k − 2 + 4 = 6; A1 k = 3.
(b) M1 P(−1) = (−1)³ + 3(−1)² − 2(−1) + 4; A1 −1 + 3 + 2 + 4; A1 8.

Paper 2 style (GDC allowed)

Question 3 [6 marks] The polynomial P(x) = 2x³ + ax² + bx − 6 has (x − 2) as a factor. When P(x) is divided by (x + 1) the remainder is −12. Find the values of a and b.
Mark schemeM1 P(2) = 0: 16 + 4a + 2b − 6 = 0; A1 2a + b = −5; M1 P(−1) = −12: −2 + a − b − 6 = −12; A1 a − b = −4; M1 solve the simultaneous equations (GDC); A1 a = −3, b = 1.
