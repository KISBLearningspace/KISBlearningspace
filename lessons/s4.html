2Study Notes

Range. Largest value − smallest value. Quick to find, but depends on two values only, so it is affected by outliers.
Interquartile range (IQR). IQR = Q₃ − Q₁, the spread of the middle 50% of the data. It is not affected by outliers.
Standard deviation σ measures the typical distance of the values from the mean x̄:
σ = √{⟦Σf(x − x̄)²|n⟧}   where n = Σf
Variance = σ² = ⟦Σf(x − x̄)²|n⟧. A larger σ means the data are more spread out. The units of σ are the units of the data; the units of the variance are squared. For grouped data use the class midpoints.
GDC. Enter the data (and frequencies) as lists, run 1-variable statistics, and read σx (the “population” standard deviation, dividing by n). Do not use sx (dividing by n − 1) in AA SL unless told.
Example 1 (by hand). Find the range, variance and standard deviation of 4, 7, 7, 9, 12, 15, 16 (mean 10).
  1. Deviations from the mean (x − 10). −6, −3, −3, −1, 2, 5, 6.
  2. Square each deviation. 36, 9, 9, 1, 4, 25, 36.
  3. Add. Sum = 120.
  4. Variance = ⟦sum of squares|n⟧. ⟦120|7⟧ ≈ 17.1.
  5. Standard deviation = √{variance}. √{⟦120|7⟧} ≈ 4.14.
  6. Range = largest − smallest. 16 − 4 = 12.
Answer: Range 12; variance ≈ 17.1; standard deviation ≈ 4.14.
Example 2 (frequency table). Goals x = 0, 1, 2, 3, 4 with frequencies 3, 5, 8, 3, 1 (n = 20, mean 1.7). Find the variance and standard deviation.
  1. Formula. Variance = ⟦Σf(x − mean)²|Σf⟧.
  2. Compute f(x − 1.7)² for each x. 3(2.89) = 8.67; 5(0.49) = 2.45; 8(0.09) = 0.72; 3(1.69) = 5.07; 1(5.29) = 5.29.
  3. Add. Σf(x − 1.7)² = 22.2.
  4. Divide by 20. Variance = ⟦22.2|20⟧ = 1.11.
  5. Square root. σ = √{1.11} ≈ 1.05.
Answer: Variance 1.11; σ ≈ 1.05 (or use the GDC list statistics).
Example 3 (compare). Two classes both have a mean mark of 50. Class A: 46, 48, 50, 52, 54. Class B: 30, 40, 50, 60, 70. Compare them.
  1. Class A deviations squared. (−4)², (−2)², 0, 2², 4² = 16, 4, 0, 4, 16, sum 40.
  2. Class A standard deviation. √{⟦40|5⟧} = √{8} ≈ 2.83.
  3. Class B deviations squared. 400, 100, 0, 100, 400, sum 1000.
  4. Class B standard deviation. √{⟦1000|5⟧} = √{200} ≈ 14.1.
  5. Compare. The means are equal, but σ is larger for B, so B is more spread out.
Answer: Class A is more consistent (σ ≈ 2.83 against 14.1).
Example 4 (grouped data). Times for 30 students: 0–10: 4, 10–20: 9, 20–30: 12, 30–40: 5. Estimate the standard deviation.
  1. Use the midpoints. 5, 15, 25, 35. The estimated mean is 21 (found in the previous lesson).
  2. Squared deviations times frequency. 4(5 − 21)² = 4(256) = 1024; 9(15 − 21)² = 9(36) = 324; 12(25 − 21)² = 12(16) = 192; 5(35 − 21)² = 5(196) = 980.
  3. Add. 1024 + 324 + 192 + 980 = 2520.
  4. Variance. ⟦2520|30⟧ = 84.
  5. Standard deviation. √{84} ≈ 9.17.
Answer: σ ≈ 9.17 min (an estimate, since midpoints were used).
Transformations. For the data y = ax + b:
• mean: ȳ = a x̄ + b
• standard deviation: σy = |a| σx (adding b does not change the spread)
• variance: σy² = a² σx²
• range and IQR are also multiplied by |a|.
Example 5 (linear transformation). A data set has mean 20 and standard deviation 4. Each value x is changed to y = 3x − 5. Find the new mean, standard deviation and variance.
  1. Mean follows the same rule as the data. New mean = 3(20) − 5 = 55.
  2. Adding or subtracting a constant does not change the spread. The −5 has no effect on σ.
  3. Multiplying by 3 multiplies the spread by 3. New σ = 3 × 4 = 12.
  4. Variance = σ². 12² = 144.
Answer: Mean 55; σ = 12; variance 144.
Example 6 (using spread to compare). Machine A fills bags with mean 250.5 g and σ = 1.9 g. Machine B has mean 251.4 g and σ = 6.9 g. Which is better?
  1. Compare the means. Both are close to 250 g on average.
  2. Compare the standard deviations. A has σ = 1.9 g and B has σ = 6.9 g, so A’s bags vary far less.
  3. Decide. Less variation means fewer bags well under or over the target.
Answer: Machine A: it is much more consistent, which is better for quality control.
Think: ① Why do we square the deviations before averaging? ② Can a standard deviation be negative? Can it be zero? ③ Why does adding 10 to every value not change σ but doubling every value doubles it?

3History & Facts

  • Karl Pearson (1893): introduced the term “standard deviation” and the symbol σ.
  • Carl Friedrich Gauss (about 1809): used the idea of squared errors in his method of least squares for astronomy.
  • Quality control: the “Six Sigma” method of manufacturing aims for defects to be six standard deviations from the target.
  • Fact: the standard deviation of Olympic 100 m sprint times is much smaller than for marathon times, because a sprint is so short.

5Real-World Applications

  • Manufacturing: small standard deviation means products are consistent (bags of rice, bolts, phone screens).
  • Finance: the standard deviation of returns is a measure of risk.
  • Sport: a player with a small σ in scores is more reliable.
  • Weather: two cities with the same mean temperature can have very different spreads (tropical versus continental).
  • Education: comparing the spread of exam results between two classes.

7Classwork & Homework

Classwork

  1. Find the range, IQR and standard deviation of 3, 5, 7, 9, 11 (use the GDC for σ).
    AnswerRange = 8. Q₁ = 4, Q₃ = 10, IQR = 6. Mean = 7, variance = ⟦40|5⟧ = 8, σ = 2√{2} ≈ 2.83.
  2. Data have mean 20 and standard deviation 4. Find the mean, σ and variance of 3x − 5.
    AnswerMean = 55, σ = 12, variance = 144.
  3. Set A: 46, 48, 50, 52, 54. Set B: 30, 40, 50, 60, 70. Both have mean 50. Which is more consistent? Give evidence.
    AnswerA: σ ≈ 2.83. B: σ ≈ 14.1. A has the smaller σ, so A is more consistent.
  4. Why is the IQR a better measure of spread than the range when there is an outlier?
    AnswerThe IQR uses only the middle 50% of the data, so one extreme value does not change it. The range uses the largest value, so an outlier changes it a lot.

Homework

  1. Machine A has weights (g): 247, 249, 250, 250, 251, 251, 252, 254. Find the mean and σ.
    AnswerMean = 250.5, σ ≈ 1.94.
  2. Machine B: 240, 245, 248, 250, 252, 255, 258, 263. Find the mean and σ and say which machine is more reliable.
    AnswerMean = 251.4, σ ≈ 6.85. Machine A is more reliable, with the smaller σ.
  3. Every value in a data set is increased by 7. What happens to the mean, σ and IQR?
    AnswerMean increases by 7; σ and IQR do not change.
  4. Show that a data set with σ = 0 has all values equal.
    Answerσ = 0 means Σ(x − x̄)² = 0, and a sum of squares is 0 only if every term is 0, so every x equals x̄.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style

Question 1 [6 marks] A data set is 3, 5, 7, 9, 11.
(a) Find the mean. [1]
(b) Show that the variance is 8. [3]
(c) Write down the standard deviation in exact form. [2]
Mark scheme(a) A1 mean = 7.
(b) M1 deviations −4, −2, 0, 2, 4; M1 squares 16, 4, 0, 4, 16 (sum 40); A1 ⟦40|5⟧ = 8.
(c) M1 σ = √{8}; A1 2√{2}.
Question 2 [6 marks] A data set has mean 20, standard deviation 4 and range 15. Each value x is changed to y = 3x − 5.
(a) Find the mean of y. [2]
(b) Find the standard deviation and the variance of y. [2]
(c) Find the range of y. [2]
Mark scheme(a) M1 3(20) − 5; A1 55.
(b) A1 σ = 12; A1 variance = 144.
(c) M1 range is multiplied by 3 (the shift does not change it); A1 45.

Paper 2 style

Question 3 [8 marks] Two machines fill bags with rice. The masses (g) of eight bags from each machine are:
Machine A: 247, 249, 250, 250, 251, 251, 252, 254
Machine B: 240, 245, 248, 250, 252, 255, 258, 263
(a) Find the mean and standard deviation for each machine. [4]
(b) Find the interquartile range of each machine. [2]
(c) The target mass is 250 g. Which machine should the factory use? Justify your answer. [2]
Mark scheme(a) A1 A: mean 250.5; A1 A: σ ≈ 1.94; A1 B: mean 251.4 (251.375); A1 B: σ ≈ 6.85.
(b) A1 A: Q₁ = 249.5, Q₃ = 251.5, IQR = 2; A1 B: Q₁ = 246.5, Q₃ = 256.5, IQR = 10.
(c) R1 means are both close to 250 g, but σ and IQR are much smaller for A; A1 use machine A because its output is more consistent and closer to the target.
