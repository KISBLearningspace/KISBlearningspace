1IB Syllabus Link & Learning Outcomes

Syllabus: Mathematics: analysis and approaches · Topic 2 Functions · SL 2.3 (graphing), SL 2.6 (quadratic function), SL 2.8 (reciprocal function and asymptotes) and SL 2.9 (exponential and logarithmic functions). Cubic, square root and absolute value are used as additional families. HL students study the same content.

Guiding questions

  • How does the equation of a function tell us the shape of its graph?
  • What do the domain and range of each family tell us about its graph?
  • Which family best models a given real situation?

Learning outcomes

  • Recognise the main function families from their equations and graphs.
  • State the domain and range of each family.
  • Identify asymptotes of simple reciprocal and exponential graphs.
  • Match a function family to a real-world situation.

Example 1. Find the range of f(x) = x² − 4x + 3.
  1. Complete the square. x² − 4x + 3 = (x − 2)² − 4 + 3 = (x − 2)² − 1.
  2. Use the smallest value of the squared bracket. (x − 2)² ≥ 0, and it equals 0 when x = 2. So f(x) ≥ 0 − 1 = −1.
  3. Decide if there is a maximum. The parabola opens upwards, so y can be as large as we like.
Answer: Range: y ≥ −1 (minimum value −1 at x = 2).
Example 2. Find the asymptotes of y = ⟦1|x⟧.
  1. Vertical asymptote. The function is undefined when the denominator is 0, so x = 0. As x gets close to 0, y becomes very large, so the graph approaches the line x = 0.
  2. Horizontal asymptote. As x becomes very large (positive or negative), ⟦1|x⟧ gets closer and closer to 0, but is never equal to 0. So y = 0.
Answer: Vertical asymptote x = 0; horizontal asymptote y = 0.
Think: Why does 2x never equal 0 or a negative number? Where do you see this on the graph?

3History & Facts

  • Nicole Oresme (about 1360): drew graphs of quantities long before coordinates were standard.
  • John Napier (1614): invented logarithms to speed up calculation.
  • Fact: pH and the decibel scale are both logarithmic scales.

5Real-World Applications

  • Linear: taxi fares and constant speed.
  • Quadratic: the path of a football or the shape of a bridge arch.
  • Exponential: population growth, radioactive decay and compound interest.
  • Logarithmic: the pH scale and earthquake or sound levels.
  • Reciprocal: time = ⟦distance|speed⟧; pressure and volume.
