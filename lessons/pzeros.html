2Study Notes

Equivalent statements. If P(x) is a polynomial and c is a real number, these are equivalent:
  • x = c is a zero of P;
  • x = c is a solution (root) of the equation P(x) = 0;
  • (x − c) is a factor of P(x);
  • (c, 0) is an x-intercept of the graph of P.
Factor theorem. (x − c) is a factor of P(x) if and only if P(c) = 0. This is the remainder theorem with remainder 0.
Strategy for a cubic. ① Try small integers c (factors of the constant term) until P(c) = 0. ② Divide by (x − c) to get a quadratic. ③ Factorise the quadratic. ④ State all the zeros.
Example 1. Factorise P(x) = x³ − 2x² − 5x + 6 completely.
  1. Look for a zero among the factors of the constant term (±1, ±2, ±3, ±6). P(1) = 1 − 2 − 5 + 6 = 0, so (x − 1) is a factor (factor theorem).
  2. Divide by (x − 1) using synthetic division with c = 1. Coefficients 1, −2, −5, 6. Bring down 1; 1 × 1 + (−2) = −1; (−1) × 1 + (−5) = −6; (−6) × 1 + 6 = 0 (remainder 0 ✓).
  3. Read the quotient. x² − x − 6.
  4. Factorise the quadratic. x² − x − 6 = (x − 3)(x + 2).
Answer: P(x) = (x − 1)(x − 3)(x + 2), with zeros 1, 3 and −2.
Example 2 (solve). Solve x³ − 7x + 6 = 0.
  1. Find one zero by trial. P(1) = 1 − 7 + 6 = 0, so x = 1 is a root and (x − 1) is a factor.
  2. Divide by (x − 1). Coefficients 1, 0, −7, 6 give 1, 1, −6, 0, so the quotient is x² + x − 6.
  3. Factorise the quotient. x² + x − 6 = (x + 3)(x − 2).
  4. Set each factor to 0. (x − 1)(x + 3)(x − 2) = 0.
Answer: x = 1, x = −3 or x = 2
Example 3 (unknown). (x + 2) is a factor of P(x) = x³ + ax² − 4x − 12. Find a and factorise P(x).
  1. Factor theorem. (x + 2) is a factor, so P(−2) = 0.
  2. Substitute x = −2. −8 + 4a + 8 − 12 = 4a − 12.
  3. Solve. 4a − 12 = 0, so a = 3.
  4. Factorise by grouping. P(x) = x³ + 3x² − 4x − 12 = x²(x + 3) − 4(x + 3) = (x + 3)(x² − 4).
  5. Difference of two squares. x² − 4 = (x − 2)(x + 2).
Answer: a = 3 and P(x) = (x + 3)(x − 2)(x + 2).
Repeated roots (multiplicity). If (x − c) appears k times in the factorised form, c is a zero of multiplicity k. The graph crosses the x-axis at a zero of odd multiplicity (and looks flat there if k = 3) and touches the x-axis at a zero of even multiplicity.
Example 4 (equation from a graph). A cubic crosses the x-axis at −2, touches it at 1 and passes through (0, 4). Find P(x).
  1. Crossing at −2. A simple factor: (x + 2).
  2. Touching at 1. The graph touches and turns back, so the root is repeated: (x − 1)².
  3. Write the general form. P(x) = a(x + 2)(x − 1)².
  4. Use (0, 4) to find a. P(0) = a(2)(1) = 2a = 4, so a = 2.
Answer: P(x) = 2(x + 2)(x − 1)²
Shape from the degree. A polynomial of degree n has at most n real zeros and at most n − 1 turning points. For large |x| it behaves like its leading term aₙxⁿ.
Even n, aₙ > 0: both ends up. Even n, aₙ < 0: both ends down. Odd n, aₙ > 0: down on the left, up on the right. Odd n, aₙ < 0: up on the left, down on the right.
Sum and product of roots (HL). For ax³ + bx² + cx + d = 0 with roots α, β, γ:
α + β + γ = −⟦b|a⟧,   αβ + βγ + γα = ⟦c|a⟧,   αβγ = −⟦d|a⟧
In Example 1 the roots 1, 3, −2 have sum 2 = −⟦−2|1⟧ and product −6 = −⟦6|1⟧ ✓.

Think: ① Why can a cubic have one, two or three real zeros, but never none? ② Why does a graph bounce off the axis at a double root? ③ Why does knowing one root make the problem easier?

3History & Facts

  • René Descartes (1637): the factor idea (a root c gives a factor x − c) was part of his work on algebra and geometry.
  • Cardano and Tartaglia (1545): found a formula for solving cubic equations in Italy, after a famous rivalry.
  • Carl Friedrich Gauss (1799): the fundamental theorem of algebra: a polynomial of degree n has exactly n roots, counting repeats, when complex numbers are allowed.
  • Abel and Ruffini (early 1800s): proved that there is no general formula using roots for equations of degree 5 or more. This is why technology and the factor theorem matter.

5Real-World Applications

  • Design and fonts: cubic Bézier curves (cubic polynomials) draw the letters in fonts, logos and animation paths.
  • Roller coasters and roads: track sections are joined smoothly using polynomials so that there are no sudden jerks.
  • Packaging: the volume of an open box cut from a sheet is a cubic function of the cut size.
  • Economics: cost curves are often modelled by cubics, with turning points showing the best output level.
  • Engineering: the bending of a beam under a load is described by a polynomial.

7Classwork & Homework

Classwork

  1. Is (x + 1) a factor of x³ + 3x² − x − 3?
    AnswerP(−1) = −1 + 3 + 1 − 3 = 0, so yes.
  2. Factorise x³ − 2x² − 5x + 6 completely.
    Answer(x − 1)(x − 3)(x + 2).
  3. Solve x³ − 7x + 6 = 0.
    Answerx = 1, x = 2 or x = −3.
  4. State the zeros of P(x) = (x + 3)(x − 2)² and the multiplicity of each.
    Answer−3 (multiplicity 1, crosses) and 2 (multiplicity 2, touches).

Homework

  1. (x − 1) is a factor of x³ + ax² − 10x + 8. Find a and factorise completely.
    AnswerP(1) = a − 1 = 0, so a = 1. Division gives x² + 2x − 8 = (x + 4)(x − 2). P(x) = (x − 1)(x + 4)(x − 2).
  2. A cubic has zeros −1, 2 and 3 and passes through (0, 12). Find its equation.
    AnswerP(x) = a(x + 1)(x − 2)(x − 3); P(0) = 6a = 12, so a = 2: P(x) = 2(x + 1)(x − 2)(x − 3).
  3. Describe the end behaviour of y = −2x⁴ + x.
    AnswerEven degree and negative leading coefficient: the graph falls on both the left and the right.
  4. Show that (x − 2) is not a factor of x³ + x − 3.
    AnswerP(2) = 8 + 2 − 3 = 7 ≠ 0.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [8 marks] Let P(x) = x³ − 2x² − 5x + 6.
(a) Show that (x − 1) is a factor of P(x). [2]
(b) Factorise P(x) completely. [3]
(c) Hence solve P(x) ≤ 0. [3]
Mark scheme(a) M1 P(1) = 1 − 2 − 5 + 6; A1 = 0, so (x − 1) is a factor.
(b) M1 division by (x − 1) giving x² − x − 6; A1 (x − 3)(x + 2); A1 P(x) = (x − 1)(x − 3)(x + 2).
(c) M1 sketch or sign table with zeros −2, 1, 3 and positive leading coefficient; A1 x ≤ −2; A1 1 ≤ x ≤ 3.
Question 2 [7 marks] The polynomial P(x) = x³ + ax² + bx + 6 has (x − 1) and (x + 3) as factors.
(a) Find the values of a and b. [5]
(b) Hence write down the third factor of P(x). [2]
Mark scheme(a) M1 P(1) = 0; A1 a + b = −7; M1 P(−3) = 0; A1 9a − 3b = 21, that is 3a − b = 7; A1 a = 0 and b = −7.
(b) M1 P(x) = x³ − 7x + 6, divide by (x − 1)(x + 3) = x² + 2x − 3 or use the product of roots; A1 (x − 2).

Paper 2 style (GDC allowed)

Question 3 [6 marks] A cubic polynomial P has zeros at x = −2 and x = 1, where the graph touches the x-axis at x = 1. The graph passes through (0, 4).
(a) Find P(x) in the form a(x − p)(x − q)². [3]
(b) Find the coordinates of the local maximum point. [2]
(c) Write down the number of solutions of P(x) = 5. [1]
Mark scheme(a) M1 P(x) = a(x + 2)(x − 1)²; M1 4 = a(2)(1); A1 P(x) = 2(x + 2)(x − 1)².
(b) M1 GDC maximum of 2x³ − 6x + 4; A1 (−1, 8).
(c) A1 3 solutions (the line y = 5 lies between the local minimum 0 and the local maximum 8).
