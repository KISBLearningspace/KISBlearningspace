2Study Notes

Identities are true for all values of θ:
sin²θ + cos²θ = 1    tan θ = ⟦sin θ|cos θ⟧
sin 2θ = 2 sin θ cos θ
cos 2θ = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ
The double angle identities are in the formula booklet. The Pythagorean identity gives sin²θ = 1 − cos²θ and cos²θ = 1 − sin²θ.
Example 1 (prove). Show that tan θ + ⟦1|tan θ⟧ = ⟦1|sin θ cos θ⟧.
  1. Start with the left side and use tan θ = ⟦sin θ|cos θ⟧. LHS = ⟦sin θ|cos θ⟧ + ⟦cos θ|sin θ⟧.
  2. Common denominator sin θ cos θ. = ⟦sin²θ + cos²θ|sin θ cos θ⟧.
  3. Use the Pythagorean identity. sin²θ + cos²θ = 1, so LHS = ⟦1|sin θ cos θ⟧ = RHS. ∎
Answer: Proved.
Example 2 (double angle). θ is acute and sin θ = ⟦3|5⟧. Find sin 2θ and cos 2θ.
  1. Find cos θ. cos θ = ⟦4|5⟧ (from the 3-4-5 triangle; positive since θ is acute).
  2. Double angle formula for sine. sin 2θ = 2 sin θ cos θ = 2(⟦3|5⟧)(⟦4|5⟧) = ⟦24|25⟧.
  3. Double angle formula for cosine (any of the three forms; use 1 − 2sin²θ). cos 2θ = 1 − 2(⟦9|25⟧) = ⟦25 − 18|25⟧ = ⟦7|25⟧.
Answer: sin 2θ = ⟦24|25⟧; cos 2θ = ⟦7|25⟧
Solving equations. ① Make it one trig function. ② Treat sin θ (or cos θ) as a letter and solve the quadratic if there is one. ③ Reject any value outside −1 to 1. ④ Find all angles in the interval using symmetry: sin: θ and 180° − θ; cos: θ and 360° − θ; tan: θ and θ + 180°. ⑤ Add 360° (or 2π) for extra turns if the interval is longer.
Example 3 (quadratic in sin). Solve 2sin²θ + sin θ − 1 = 0 for 0° ≤ θ ≤ 360°.
  1. Treat sin θ as a single unknown. It is a quadratic in s = sin θ: 2s² + s − 1 = 0.
  2. Factorise. (2s − 1)(s + 1) = 0, so sin θ = ⟦1|2⟧ or sin θ = −1.
  3. sin θ = ⟦1|2⟧. Q1: 30°. Q2: 180° − 30° = 150°.
  4. sin θ = −1. θ = 270°.
Answer: θ = 30°, 150°, 270°
Example 4 (use the identity). Solve 2cos²θ = 3 sin θ for 0° ≤ θ ≤ 360°.
  1. Get a single trig function. Replace cos²θ = 1 − sin²θ: 2(1 − sin²θ) = 3 sin θ.
  2. Rearrange to a quadratic. 2 − 2sin²θ = 3 sin θ, so 2sin²θ + 3 sin θ − 2 = 0.
  3. Factorise. (2 sin θ − 1)(sin θ + 2) = 0.
  4. Reject impossible values. sin θ = −2 is impossible. So sin θ = ⟦1|2⟧.
  5. Solve. θ = 30° or 180° − 30° = 150°.
Answer: θ = 30°, 150°
Example 5 (double angle). Solve sin 2x = sin x for 0 ≤ x ≤ 2π.
  1. Use sin 2x = 2 sin x cos x. 2 sin x cos x = sin x.
  2. Move everything to one side (do not divide by sin x). 2 sin x cos x − sin x = 0.
  3. Factorise. sin x (2cos x − 1) = 0.
  4. sin x = 0. x = 0, π, 2π.
  5. cos x = ⟦1|2⟧. x = ⟦π|3⟧ or 2π − ⟦π|3⟧ = ⟦5π|3⟧.
Answer: x = 0, ⟦π|3⟧, π, ⟦5π|3⟧, 2π (dividing by sin x would lose 0, π and 2π).
Example 6 (a multiple angle). Solve cos 2x = ⟦1|2⟧ for 0° ≤ x ≤ 360°.
  1. Substitute u = 2x. Then cos u = ⟦1|2⟧.
  2. Extend the range. 0° ≤ x ≤ 360° means 0° ≤ u ≤ 720° (two full turns).
  3. Solve for u. Cos is positive in Q1 and Q4: u = 60°, 300° in the first turn; add 360°: 420°, 660°.
  4. Divide by 2 to get x. x = 30°, 150°, 210°, 330°.
Answer: x = 30°, 150°, 210°, 330°
Think: ① How would you convince someone that sin²θ + cos²θ = 1 is an identity and not an equation? ② Why does cos 2θ have three forms, and when is each most useful? ③ What would a graphing calculator show if you plotted both sides of an identity?

3History & Facts

  • Ptolemy (about 150 CE): his theorem on cyclic quadrilaterals gave the sum and difference formulas, from which the double angle follows.
  • François Viète (1500s): developed many identities and used them to solve algebraic problems.
  • Euler (1700s): linked sine and cosine to the exponential function, which explains why so many identities exist.
  • Fact: the identity cos 2θ = 1 − 2sin²θ is the reason the intensity of polarised light changes as the square of a cosine (Malus’s law).

5Real-World Applications

  • Signal processing: sound and radio waves are sums of sines; identities simplify them.
  • Engineering: alternating current, power = voltage × current uses sin² and cos².
  • Physics: projectile range uses sin 2θ, which is largest at 45°.
  • Optics: intensity of polarised light changes as cos².
  • Computer graphics: rotations are written with sine and cosine and combined with identities.

7Classwork & Homework

Classwork

  1. Simplify ⟦1 − cos²θ|sin θ⟧.
    Answer⟦sin²θ|sin θ⟧ = sin θ.
  2. θ is acute and cos θ = ⟦1|3⟧. Find sin θ, sin 2θ and cos 2θ.
    Answersin θ = ⟦2√{2}|3⟧; sin 2θ = ⟦4√{2}|9⟧; cos 2θ = 2(⟦1|9⟧) − 1 = −⟦7|9⟧.
  3. Solve 2sin θ − 1 = 0 for 0° ≤ θ ≤ 360°.
    Answerθ = 30° or 150°.
  4. Solve 2sin²θ + sin θ − 1 = 0 for 0° ≤ θ ≤ 360°.
    Answersin θ = ⟦1|2⟧ or −1; θ = 30°, 150°, 270°.

Homework

  1. Show that ⟦sin 2θ|2 sin θ⟧ = cos θ.
    Answer⟦2 sin θ cos θ|2 sin θ⟧ = cos θ.
  2. Solve 2cos²x = 3 sin x for 0° ≤ x ≤ 360°.
    AnswerUse cos²x = 1 − sin²x: 2sin²x + 3 sin x − 2 = 0; sin x = ⟦1|2⟧; x = 30°, 150°.
  3. Solve sin 2x = sin x for 0 ≤ x ≤ 2π.
    Answersin x(2cos x − 1) = 0; x = 0, ⟦π|3⟧, π, ⟦5π|3⟧, 2π.
  4. Solve 3cos²θ = 2 − sin θ for 0° ≤ θ ≤ 360°.
    Answer3 − 3sin²θ = 2 − sin θ gives 3sin²θ − sin θ − 1 = 0; sin θ = 0.768 or −0.434; θ = 50.1°, 129.9°, 205.7°, 334.3°.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] θ is acute and cos θ = ⟦1|3⟧. Find the exact value of (a) sin θ [2] (b) sin 2θ [2] (c) cos 2θ [2].
Mark scheme(a) M1 sin²θ = 1 − ⟦1|9⟧; A1 sin θ = ⟦2√{2}|3⟧.
(b) M1 2 sin θ cos θ; A1 ⟦4√{2}|9⟧.
(c) M1 2cos²θ − 1; A1 −⟦7|9⟧.
Question 2 [6 marks] Solve sin 2x = sin x for 0 ≤ x ≤ 2π.
Mark schemeM1 sin 2x = 2 sin x cos x; M1 sin x(2cos x − 1) = 0; A1 sin x = 0, so x = 0, π, 2π; A1 cos x = ⟦1|2⟧; A1 x = ⟦π|3⟧; A1 x = ⟦5π|3⟧.

Paper 2 style (GDC allowed)

Question 3 [7 marks] (a) Show that the equation 3cos²θ = 2 − sin θ can be written as 3sin²θ − sin θ − 1 = 0. [2]
(b) Hence solve the equation for 0° ≤ θ ≤ 360°. [5]
Mark scheme(a) M1 cos²θ = 1 − sin²θ; A1 3 − 3sin²θ = 2 − sin θ, rearranged to 3sin²θ − sin θ − 1 = 0.
(b) M1 quadratic formula with s = sin θ; A1 s = ⟦1 + √{13}|6⟧ ≈ 0.768 and s ≈ −0.434; A1 θ = 50.1° and 129.9° (from s = 0.768); A1 θ = 205.7° and 334.3° (from s = −0.434); A1 four solutions and no others (R1 for no extra values).
