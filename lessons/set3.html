Learning outcomes

  • Solve survey problems with two sets.

2Study Notes

Union. A ∪ B is the set of elements that are in A or in B or in both. Think “join together”, listing each element once.
Intersection. A ∩ B is the set of elements that are in both A and B. Think “the overlap”.
Disjoint sets. If A ∩ B = ∅ the sets have nothing in common. They are also called mutually exclusive. Their circles do not overlap.
Counting formula. n(A ∪ B) = n(A) + n(B) − n(A ∩ B). When we add n(A) and n(B), the elements in the overlap are counted twice, so we subtract them once. If A and B are disjoint, n(A ∪ B) = n(A) + n(B).

Example 1 (union and intersection from lists). A = {1, 2, 3, 4, 5} and B = {4, 5, 6, 7}. List A ∪ B and A ∩ B.
  1. For A ∩ B, find the elements in both lists. 4 and 5 appear in both. A ∩ B = {4, 5}.
  2. For A ∪ B, write every element that is in either list, without repeats. 1, 2, 3, 4, 5, 6, 7.
  3. Write A ∪ B. A ∪ B = {1, 2, 3, 4, 5, 6, 7}.
  4. Check the counting formula. n(A) = 5, n(B) = 4, n(A ∩ B) = 2, so 5 + 4 − 2 = 7 = n(A ∪ B) ✓.
Answer: A ∪ B = {1, 2, 3, 4, 5, 6, 7}; A ∩ B = {4, 5}.
Example 2 (disjoint sets). E = {2, 4, 6} and O = {1, 3, 5}. Find E ∩ O and n(E ∪ O).
  1. Look for common elements. There are none.
  2. So the intersection is empty. E ∩ O = ∅, so the sets are disjoint.
  3. Count the union by adding. n(E ∪ O) = 3 + 3 = 6.
Answer: E ∩ O = ∅; n(E ∪ O) = 6.
Example 3 (union and intersection from a rule). ξ = {1, …, 20}. A = {multiples of 3}, B = {multiples of 4}. Find A ∩ B and A ∪ B.
  1. List A. {3, 6, 9, 12, 15, 18}.
  2. List B. {4, 8, 12, 16, 20}.
  3. Common elements. Only 12. So A ∩ B = {12}.
  4. Join the lists, writing 12 once. A ∪ B = {3, 4, 6, 8, 9, 12, 15, 16, 18, 20}.
  5. Check the count. 6 + 5 − 1 = 10 and the list has 10 elements ✓.
Answer: A ∩ B = {12}; A ∪ B has 10 elements.
Example 4 (use the formula). n(A) = 15, n(B) = 12 and n(A ∩ B) = 5. Find n(A ∪ B).
  1. Write the formula. n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
  2. Substitute. 15 + 12 − 5.
  3. Calculate. 22.
Answer: n(A ∪ B) = 22.
Example 5 (find the overlap). n(A ∪ B) = 30, n(A) = 20 and n(B) = 17. Find n(A ∩ B).
  1. Substitute in the formula. 30 = 20 + 17 − n(A ∩ B).
  2. Simplify. 30 = 37 − n(A ∩ B).
  3. Rearrange. n(A ∩ B) = 37 − 30 = 7.
Answer: n(A ∩ B) = 7.
Example 6 (a survey, step by step). In a class of 30 students, 18 study French (F), 14 study Spanish (S) and 6 study both. How many study neither?
  1. Start with the overlap, so that nobody is counted twice. Both: 6.
  2. French only = total French minus both. 18 − 6 = 12.
  3. Spanish only = total Spanish minus both. 14 − 6 = 8.
  4. Number studying at least one language. 12 + 6 + 8 = 26.
  5. Neither = total minus the union. 30 − 26 = 4.
  6. Check with the formula. n(F ∪ S) = 18 + 14 − 6 = 26 ✓.
Answer: 4 students study neither.
Example 7 (describe regions in symbols). ξ = {1, …, 10}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Find A ∩ B′, A′ ∩ B and (A ∪ B)′.
  1. A ∩ B′ means in A but not in B. Remove 3, 4 from A: {1, 2}.
  2. A′ ∩ B means in B but not in A. Remove 3, 4 from B: {5, 6}.
  3. (A ∪ B)′ means in neither. A ∪ B = {1, …, 6}, so {7, 8, 9, 10}.
Answer: A ∩ B′ = {1, 2}; A′ ∩ B = {5, 6}; (A ∪ B)′ = {7, 8, 9, 10}.
Example 8 (a check on complements). Using Example 7, show that (A ∪ B)′ = A′ ∩ B′.
  1. Find A′ and B′. A′ = {5, 6, 7, 8, 9, 10}, B′ = {1, 2, 7, 8, 9, 10}.
  2. Find the elements in both. A′ ∩ B′ = {7, 8, 9, 10}.
  3. Compare. This equals (A ∪ B)′ = {7, 8, 9, 10} ✓. (A number in neither set is not in A and not in B.)
Answer: Both give {7, 8, 9, 10}.
Common mistakes.
① Writing A ∪ B with repeated elements. List each element once.
② Adding n(A) + n(B) and forgetting to subtract the overlap.
③ Mixing up ∪ and ∩. The ∪ looks like a cup that collects everything.
④ Using “A only” and “A” as if they were the same. n(A) includes the overlap.

3History & Facts

  • George Boole (1815–1864): his algebra of logic treats “and”, “or”, “not” like operations on sets.
  • Augustus De Morgan (1806–1871): found that (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.
  • Symbols ∪ and ∩: introduced by Peano in 1888.
  • Today: every database search with AND or OR is a set operation.

5Real-World Applications

  • Web search: “cats OR dogs” is a union; “cats AND dogs” is an intersection.
  • School clubs: students in both Chess and Robotics form the intersection.
  • Health surveys: people with at least one symptom form the union.
  • Marketing: customers who bought product A or B, and those who bought both.
  • Probability: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).

Homework

  1. ξ = {1, …, 12}, A = {even numbers}, B = {multiples of 3}. List A ∩ B and A ∪ B.
    AnswerA = {2, 4, 6, 8, 10, 12}, B = {3, 6, 9, 12}. A ∩ B = {6, 12}; A ∪ B = {2, 3, 4, 6, 8, 9, 10, 12}.
  2. n(A ∪ B) = 40, n(A) = 25, n(B) = 22. Find n(A ∩ B).
    Answer40 = 47 − n(A ∩ B), so 7.

Mark scheme(a) A1 {3, 5, 7}. (b) A1 {1, 2, 3, 5, 7, 9, 11}. (c) A1 7.
Question 2 [4 marks] n(ξ) = 40, n(A) = 22, n(B) = 18, n(A ∩ B) = 7. Find (a) n(A ∪ B) [2] (b) n(A ∪ B)′ [2].
Mark scheme(a) M1 22 + 18 − 7; A1 33. (b) M1 40 − 33; A1 7.
Question 3 [3 marks] Use ξ = {1, …, 10}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. (a) List A′ ∩ B. [1] (b) Show that (A ∩ B)′ has 8 elements. [2]
Mark scheme(a) A1 {5, 6}. (b) M1 A ∩ B = {3, 4}; A1 10 − 2 = 8.

Paper 2 style

Question 4 [7 marks] In a school of 120 students, 70 take Physics (P), 55 take Chemistry (C) and 20 take neither. (a) Find the number who take at least one of the two. [1] (b) Find n(P ∩ C). [2] (c) Draw a Venn diagram with the numbers in each region. [3] (d) How many take Physics only? [1]
Mark scheme(a) A1 120 − 20 = 100. (b) M1 70 + 55 − n(P ∩ C) = 100; A1 25. (c) A1 25 in the overlap; A1 45 and 30 in the two outer regions; A1 20 outside. (d) A1 45.
