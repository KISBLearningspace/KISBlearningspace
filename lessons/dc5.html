Increasing, Decreasing and Stationary Points

KISB Diploma Programme · Mathematics: analysis and approaches · Differentiation · AA SL 5 · notes · lab · practice · exam-style questions · IA ideas

Syllabus: Mathematics: analysis and approaches · Topic 5 Calculus · increasing and decreasing functions; stationary points; local maximum and minimum; the second derivative and its use in testing; points of inflexion. Check your subject guide for the exact wording.

Guiding questions

  • What does the sign of f′(x) tell us about the graph?
  • How can we find and classify maximum and minimum points?
  • What does the second derivative tell us about the shape of a curve?

Learning outcomes

  • Use f′(x) > 0 and f′(x) < 0 to find where f is increasing or decreasing.
  • Find stationary points by solving f′(x) = 0.
  • Classify them using a sign table or the second derivative f″(x).
  • Describe concavity and find points of inflexion.
  • Find unknown constants from information about stationary points.

2Study Notes

Increasing and decreasing. f′(x) > 0: f is increasing. f′(x) < 0: f is decreasing.
Stationary point. A point where f′(x) = 0 (the tangent is horizontal). It can be a local maximum, a local minimum, or a horizontal point of inflexion.
Second derivative test (at a stationary point, f′(a) = 0)
f″(a) > 0: minimum f″(a) < 0: maximum f″(a) = 0: test with signs
First derivative (sign) test. If f′ changes from + to − the point is a maximum; from − to + a minimum; no change gives a horizontal inflexion.
Concavity and inflexion. f″(x) > 0: concave up (∪). f″(x) < 0: concave down (∩). A point of inflexion is where the concavity changes: f″ changes sign (f″ = 0 is needed but not enough).

Example 1 (quadratic). Find where f(x) = x² − 6x + 5 is increasing or decreasing, and the stationary point.
  1. f′(x) = 2x − 6. Zero at x = 3
  2. Signs. f′ < 0 for x < 3 (decreasing), f′ > 0 for x > 3 (increasing)
  3. y-value. f(3) = −4
Answer: Decreasing x < 3; increasing x > 3; minimum (3, −4)
Example 2 (cubic with the second derivative). For f(x) = x³ − 6x² + 9x + 1, find the stationary points and classify them.
  1. f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3). x = 1 or x = 3
  2. f″(x) = 6x − 12. f″(1) = −6 (max), f″(3) = 6 (min)
  3. y-values. f(1) = 5, f(3) = 1
Answer: Maximum (1, 5); minimum (3, 1)
Example 3 (sign table). Find and classify the stationary points of f(x) = x³ − 3x using a sign table.
  1. f′(x) = 3x² − 3 = 3(x − 1)(x + 1). x = −1, 1
  2. Signs of f′: + (x < −1), − (−1 < x < 1), + (x > 1). Max at x = −1, min at x = 1
  3. y-values. f(−1) = 2, f(1) = −2
Answer: Max (−1, 2); min (1, −2)
Example 4 (second derivative). f(x) = 2x³ − 9x² + 12x. Classify the stationary points.
  1. f′(x) = 6x² − 18x + 12 = 6(x − 1)(x − 2). x = 1, 2
  2. f″(x) = 12x − 18. f″(1) = −6, f″(2) = 6
  3. y-values. f(1) = 5, f(2) = 4
Answer: Max (1, 5); min (2, 4)
Example 5 (inflexion). Show that f(x) = x³ has a horizontal point of inflexion at the origin.
  1. f′(x) = 3x², f″(x) = 6x. f′(0) = 0 and f″(0) = 0
  2. Signs of f′. + on both sides of 0
  3. f″ changes sign at 0. From − to +
Answer: (0, 0) is a horizontal point of inflexion.
Example 6 (concavity). For f(x) = x³ − 3x², where is the graph concave up?
  1. f″(x) = 6x − 6. 6x − 6 > 0
Answer: x > 1 (inflexion at x = 1)
Example 7 (find constants). f(x) = ax² + bx has a minimum at (2, −4). Find a and b.
  1. f′(x) = 2ax + b = 0 at x = 2. 4a + b = 0
  2. f(2) = −4. 4a + 2b = −4
  3. Solve: b = −4a. 4a − 8a = −4, a = 1, b = −4
Answer: a = 1, b = −4
Example 8 (real context). The height of a ball is h = −5t² + 20t metres. When is the height greatest and what is it?
  1. h′(t) = −10t + 20 = 0. t = 2
  2. h(2) = −20 + 40. 20 m
Answer: t = 2 s, maximum 20 m
Common mistakes.
① Saying every stationary point is a maximum or a minimum (inflexions exist).
② Forgetting to find the y-value of the stationary point.
③ Using f″(a) = 0 to say “inflexion” without checking a sign change.
④ Mixing up the sign of f″ and the type (f″ > 0 is a minimum).
⑤ Describing “increasing” by values of f instead of values of x.

3History & Facts

  • Pierre de Fermat (1630s): found maxima and minima by looking for places where a curve is momentarily flat.
  • Colin Maclaurin and others (1700s): used the second derivative to classify turning points.
  • Today: maxima and minima are the basis of optimisation in engineering, economics and machine learning.

5Real-World Applications

  • Business: finding the price that gives maximum profit.
  • Engineering: the lowest point of a cable or the top of an arch.
  • Science: equilibrium points where change stops.
  • Health: peak drug concentration and when it falls.
  • Sport: the highest point of a jump.

7Classwork & Homework

Classwork

  1. For f(x) = x² − 4x + 7, find the stationary point and its nature.
    Answerf′ = 2x − 4 = 0, x = 2, f(2) = 3: minimum (2, 3)
  2. Where is f(x) = x³ − 12x decreasing?
    Answerf′ = 3x² − 12 < 0: −2 < x < 2
  3. Find f″ for f(x) = x⁴.
    Answer12x²
  4. Classify the stationary point of y = −x² + 6x.
    Answerx = 3, y = 9: maximum (3, 9)

Homework

  1. Find and classify the stationary points of f(x) = x³ − 3x² + 2.
    Answerf′ = 3x(x − 2): (0, 2) max, (2, −2) min
  2. Where is f(x) = 2x² − 8x concave up?
    Answerf″ = 4 > 0 for all x
  3. Find the inflexion of f(x) = x³ − 6x².
    Answerf″ = 6x − 12 = 0, x = 2, f(2) = −16
  4. f(x) = x² + kx has a stationary point at x = 3. Find k.
    Answer2x + k = 0 at x = 3: k = −6

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. No calculator. Open “Mark scheme” only after trying.

Paper 1 style

Question 1 [4 marks] Find the coordinates of the stationary points of f(x) = x³ − 3x² − 9x + 5 and determine their nature. [4]
Mark schemeM1 f′ = 3x² − 6x − 9 = 3(x − 3)(x + 1); A1 x = 3, −1; M1 f″ = 6x − 6: f″(3) = 12 > 0, f″(−1) = −12 < 0; A1 min (3, −22), max (−1, 10).
Question 2 [3 marks] Find the values of x for which f(x) = x³ − 6x² + 5 is decreasing. [3]
Mark schemeM1 f′ = 3x² − 12x < 0; A1 3x(x − 4) < 0; A1 0 < x < 4.
Question 3 [3 marks] The graph of f(x) = x³ + ax² has a point of inflexion at x = 2. Find a. [3]
Mark schemeM1 f″ = 6x + 2a; M1 12 + 2a = 0; A1 a = −6.

Paper 2 style

Question 4 [8 marks] A function is f(x) = 2x³ − 9x² + 12x + 3. (a) Find f′(x) and the x-coordinates of the stationary points. [3] (b) Use f″ to classify them. [3] (c) Write down the values of x for which f is increasing. [2]
Mark scheme(a) A1 f′ = 6x² − 18x + 12; M1 6(x − 1)(x − 2) = 0; A1 x = 1, 2. (b) A1 f″ = 12x − 18; A1 f″(1) = −6, max; A1 f″(2) = 6, min. (c) M1 f′ > 0; A1 x < 1 or x > 2.
