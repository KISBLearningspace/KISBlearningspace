Box-and-Whisker Plots

1IB Syllabus Link & Learning Outcomes

Syllabus: IB Mathematics: analysis and approaches, SL 4.2 (box-and-whisker diagrams, including outliers, and comparing data sets).
Textbook references (sections only, no copied text)

Guiding questions

  • How can five numbers show the shape and spread of a whole data set?
  • What does each part of a box plot tell us?
  • How do we compare two data sets using box plots?

Learning outcomes

  • Write the five-number summary (minimum, Q₁, median, Q₃, maximum).
  • Draw and read a box-and-whisker plot, including outliers.
  • Say what percentage of the data lies in each part of the plot.
  • Describe symmetry or skew from a box plot.
  • Compare two box plots using the median and the spread (IQR, range).

2Study Notes

Five-number summary: minimum, lower quartile Q₁, median, upper quartile Q₃, maximum.
Box plot (box-and-whisker diagram). Draw a number line. Draw a box from Q₁ to Q₃ with a line at the median. Draw whiskers from the box to the minimum and to the maximum.
Outliers. Use the 1.5 × IQR rule. A value beyond Q₁ − 1.5 × IQR or Q₃ + 1.5 × IQR is marked with a cross ×. The whisker then goes only to the largest (or smallest) value that is not an outlier.
What the parts mean. Each of the four sections (lower whisker, lower half of box, upper half of box, upper whisker) contains about 25% of the data. The box holds the middle 50%. The width of the box is the IQR. The total length from end to end is the range (when there are no outliers).
Skew. If the median is near the centre of the box and the whiskers have similar lengths, the data are roughly symmetric. If the upper whisker or upper part of the box is longer, the data are positively skewed (a tail to the right). If the lower side is longer, the data are negatively skewed.
Comparing two data sets. Always compare a measure of centre (median) and a measure of spread (IQR or range), and write the answer in context.

Example 1 (five numbers to box plot). Minimum 2, Q₁ = 5, median = 8, Q₃ = 12, maximum 20. Describe the plot and find the range and IQR.
  1. Draw a number line from 0 to 22. Choose a scale where all five values fit.
  2. Draw the box from 5 to 12 with a line at 8. The box is the middle 50%.
  3. Draw the whiskers to 2 and to 20. They show the minimum and maximum.
  4. Range = max − min. 20 − 2 = 18.
  5. IQR = Q₃ − Q₁. 12 − 5 = 7.
Answer: Range 18, IQR 7.
Example 2 (read a box plot). A box plot of 80 test scores has min 20, Q₁ = 45, median 58, Q₃ = 70, max 95. How many scores are between 45 and 70? What fraction scored above 58?
  1. The box (Q₁ to Q₃) holds the middle 50%. 0.5 × 80 = 40 scores.
  2. The median splits the data in half. Half scored above 58, so ⟦1|2⟧ (40 scores).
Answer: 40 scores; half scored above 58.
Example 3 (five-number summary from data). Find the five-number summary of 52, 55, 56, 58, 59, 60, 61, 63, 64, 66, 90 and test for outliers.
  1. Order is already given. n = 11. The median is the 6th value: 60.
  2. Halves without the median. Lower: 52, 55, 56, 58, 59 so Q₁ = 56. Upper: 61, 63, 64, 66, 90 so Q₃ = 64.
  3. IQR and upper fence. IQR = 8; fence = 64 + 12 = 76.
  4. Is 90 beyond the fence? 90 > 76, so 90 is an outlier and gets a cross.
  5. The upper whisker goes to the largest non-outlier. 66.
Answer: Min 52, Q₁ 56, median 60, Q₃ 64, whisker to 66, outlier 90.
Example 4 (compare two classes). Class A: min 40, Q₁ 55, median 62, Q₃ 70, max 90. Class B: min 30, Q₁ 52, median 65, Q₃ 82, max 95. Compare them.
  1. Compare the centres (medians). A: 62. B: 65. Class B is slightly higher on average.
  2. Compare the IQRs. A: 70 − 55 = 15. B: 82 − 52 = 30. B’s middle 50% is twice as spread out.
  3. Compare the ranges. A: 90 − 40 = 50. B: 95 − 30 = 65.
  4. Write a conclusion in context. Class B has a slightly higher median but is much less consistent, while class A’s scores are closer together.
Answer: B higher median; A more consistent (smaller IQR).
Example 5 (skewness). A box plot has Q₁ = 10, median = 12, Q₃ = 25, max = 60 and min = 5. Comment on the shape.
  1. Compare the two halves of the box. Median − Q₁ = 2 and Q₃ − median = 13.
  2. Compare the whiskers. Upper whisker 60 − 25 = 35; lower whisker 10 − 5 = 5.
  3. The upper side is longer. The data are positively skewed (a long tail to the high values).
Answer: Positively skewed.
Example 6 (percentages). A box plot is drawn from 200 values. How many values are below Q₁? above the median? below Q₃?
  1. Each section holds 25% of the data. 25% of 200 = 50.
  2. Below Q₁. 50 values.
  3. Above the median. 100 values.
  4. Below Q₃. 150 values.
Answer: 50, 100 and 150.
Example 7 (drawing with an outlier). Data 4, 6, 7, 8, 9, 10, 12, 30. Say where the whiskers and the cross go.
  1. Q₁ = 6.5, median = 8.5, Q₃ = 11 and the outlier 30 (fence 17.75). The box is from 6.5 to 11 with the median line at 8.5.
  2. The lower whisker goes to the minimum. 4.
  3. The upper whisker goes to the largest value inside the fence. 12.
  4. Mark the outlier. A cross × at 30.
Answer: Box 6.5 to 11, median 8.5, whiskers 4 to 12, cross at 30.
Common mistakes.
① Drawing the box from the minimum to the maximum. The box is Q₁ to Q₃.
② Drawing the whisker to an outlier instead of using a cross.
③ Saying “the larger box has more data”. Each part has the same number of data values (25%); the length shows the spread.
④ Comparing only the medians. Always compare the spread too.
⑤ Not using a scale on the number line.

3History & Facts

  • John Tukey (1915–2000): invented the box plot in 1970 as part of “exploratory data analysis”.
  • Mary Eleanor Spear (1950s): designed a similar “range bar”, which later influenced box plots.
  • Today: box plots appear in science reports, finance and medicine to compare groups quickly.

5Real-World Applications

  • Comparing schools or classes: two box plots on one axis show which group does better and which is more consistent.
  • Medicine: comparing recovery times for two treatments.
  • Weather: monthly temperature ranges in different cities.
  • Business: delivery times of two couriers.
  • Sport: distribution of race times.

6IB Links: TOK, International-mindedness & ATL

  • TOK: A box plot hides the individual values. What do we gain and lose by summarising data?
  • International-mindedness: Tukey’s exploratory approach is used by statisticians worldwide.
  • ATL: communication (writing conclusions in context), thinking (not judging from the median alone).
  • IA ideas: compare two groups (for example sleep hours of boys and girls) using side-by-side box plots.

7Classwork & Homework

Classwork

  1. Write the range and IQR for: min 5, Q₁ 12, median 18, Q₃ 25, max 40.
    AnswerRange 35; IQR 13.
  2. n = 120. How many values are above Q₃?
    Answer25% of 120 = 30.
  3. Where does an outlier go on a box plot?
    AnswerIt is marked with a cross beyond the whisker.
  4. The median is much closer to Q₁ than Q₃. Describe the skew.
    AnswerPositively skewed.

Homework

  1. Find the five-number summary for 3, 5, 6, 8, 9, 12, 15.
    AnswerMin 3, Q₁ 5, median 8, Q₃ 12, max 15.
  2. Class A: median 55, IQR 10. Class B: median 60, IQR 25. Compare.
    AnswerB has the higher median; A is more consistent (smaller IQR).
  3. A box plot has Q₁ = 30 and Q₃ = 50, and a value of 95. Is it an outlier?
    AnswerIQR 20; fence 50 + 30 = 80; 95 > 80, so yes.
  4. True or false: a longer box means more data values.
    AnswerFalse. Each section has about 25% of the data. A longer box means a bigger spread.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. No calculator. Open “Mark scheme” only after trying.

Paper 1 style

Question 1 [4 marks] A box plot shows: minimum 12, Q₁ = 20, median = 26, Q₃ = 35, maximum 58. (a) Find the range. [1] (b) Find the IQR. [1] (c) Test whether 58 is an outlier. [2]
Mark scheme(a) A1 46. (b) A1 15. (c) M1 35 + 1.5 × 15 = 57.5; A1 58 > 57.5, so yes, an outlier.
Question 2 [3 marks] A data set of 80 values is summarised by a box plot. (a) How many values lie between Q₁ and Q₃? [1] (b) How many values are greater than Q₃? [1] (c) Explain why the whiskers could be different lengths even though they each contain 25% of the data. [1]
Mark scheme(a) A1 40. (b) A1 20. (c) R1 the values in a whisker can be spread over a longer or shorter interval.
Question 3 [3 marks] Class P: median 64, IQR 10. Class Q: median 60, IQR 22. Compare the classes. [3]
Mark schemeA1 P has the higher median; A1 P has the smaller IQR; R1 so P scores higher and more consistently, in context.

Paper 2 style

Question 4 [7 marks] The times (minutes) of 9 students to complete a puzzle: 12, 15, 16, 18, 19, 21, 24, 26, 55. (a) Find the five-number summary. [3] (b) Show that 55 is an outlier. [2] (c) Describe the shape of the box plot. [2]
Mark scheme(a) A1 median 19; A1 Q₁ = (15 + 16) ÷ 2 = 15.5; A1 Q₃ = (24 + 26) ÷ 2 = 25, with min 12 and max 55. (b) M1 IQR = 9.5, upper fence 25 + 14.25 = 39.25; A1 55 > 39.25. (c) A1 the median is nearer Q₁ and the upper whisker is longer; A1 positively skewed.
