2Study Notes

Key identity
x² + bx = (x + ⟦b|2⟧)² − (⟦b|2⟧)²
so
x² + bx + c = (x + ⟦b|2⟧)² + c − ⟦b²|4⟧
Halve the coefficient of x, put it in the bracket, then subtract its square.
Picture it. The expression x² + bx is a square of side x plus two strips, each ⟦b|2⟧ by x. Moving the strips to two sides of the square leaves a missing corner of area (⟦b|2⟧)². Adding that corner “completes” the square, so we must subtract it again. Try the area model in Lab B.
Example 1. Complete the square for x² + 6x + 2.
  1. Half the coefficient of x. Half of 6 is 3.
  2. Form the square. (x + 3)² = x² + 6x + 9. This has 9 too many, so subtract 9.
  3. Rewrite. x² + 6x + 2 = (x + 3)² − 9 + 2.
  4. Simplify. = (x + 3)² − 7.
Answer: (x + 3)² − 7. The vertex of y = x² + 6x + 2 is (−3, −7).
Example 2. Complete the square for x² − 8x + 3.
  1. Half the coefficient of x. Half of −8 is −4.
  2. Form the square. (x − 4)² = x² − 8x + 16, which has 16 too many.
  3. Rewrite. x² − 8x + 3 = (x − 4)² − 16 + 3 = (x − 4)² − 13.
Answer: (x − 4)² − 13
When a ≠ 1. Factor a out of the x² and x terms only, complete the square inside, then multiply out the outer a.
ax² + bx + c = a(x + ⟦b|2a⟧)² + c − ⟦b²|4a⟧
Example 3 (a ≠ 1). Complete the square for 2x² + 12x + 5.
  1. Factor 2 out of the x terms only. 2x² + 12x + 5 = 2(x² + 6x) + 5.
  2. Complete the square inside the bracket. x² + 6x = (x + 3)² − 9.
  3. Substitute back. 2[(x + 3)² − 9] + 5.
  4. Multiply out the 2 and combine constants. 2(x + 3)² − 18 + 5 = 2(x + 3)² − 13.
Answer: 2(x + 3)² − 13. Vertex (−3, −13), minimum value −13.
Example 4 (odd coefficient). Complete the square for x² + 5x + 1.
  1. Half the coefficient of x. Half of 5 is ⟦5|2⟧.
  2. Form the square. (x + ⟦5|2⟧)² = x² + 5x + ⟦25|4⟧, so subtract ⟦25|4⟧.
  3. Combine the constants. −⟦25|4⟧ + 1 = −⟦25|4⟧ + ⟦4|4⟧ = −⟦21|4⟧.
Answer: (x + ⟦5|2⟧)² − ⟦21|4⟧
Example 5 (negative a). Complete the square for −x² + 4x + 1.
  1. Factor −1 out of the x terms. −x² + 4x + 1 = −(x² − 4x) + 1.
  2. Complete the square inside. x² − 4x = (x − 2)² − 4.
  3. Substitute back. −[(x − 2)² − 4] + 1 = −(x − 2)² + 4 + 1.
Answer: −(x − 2)² + 5. Vertex (2, 5), maximum value 5.
Example 6 (solving). Solve (a) x² + 6x − 7 = 0 and (b) x² + 4x − 1 = 0 by completing the square.
  1. (a) Complete the square. (x + 3)² − 9 − 7 = 0, so (x + 3)² = 16.
  2. (a) Take square roots (both signs). x + 3 = ±4, so x = 1 or x = −7.
  3. (b) Complete the square. (x + 2)² − 4 − 1 = 0, so (x + 2)² = 5.
  4. (b) Take square roots. x + 2 = ±√{5}, so x = −2 ± √{5}.
Answer: (a) x = 1 or x = −7. (b) x = −2 ± √{5} (exact); a calculator gives x ≈ 0.236 or x ≈ −4.24.
Why the quadratic formula works. Start with ax² + bx + c = 0 and complete the square:
(x + ⟦b|2a⟧)² = ⟦b² − 4ac|4a²⟧
Take square roots:
x = ⟦−b ± √{b² − 4ac}|2a⟧

Technology (GDC / Desmos)

Graph y = x² + 6x + 2 and y = (x + 3)² − 7. The curves coincide, which confirms the algebra. The GDC minimum gives the vertex.

Think: ① Why do we halve b and not just use b? ② What does the completed form tell you about the smallest value of x² + bx + c? ③ Can every quadratic be written in completed-square form?

3History & Facts

  • Babylonian scribes (about 2000 BCE): solved area problems that lead to quadratic equations by rearranging squares and rectangles.
  • Muhammad ibn Musa al-Khwarizmi (about 820 CE): in Baghdad he gave general methods, with geometric proofs, for solving quadratic equations. The word “algebra” comes from his book title al-jabr, and “algorithm” comes from his name.
  • Brahmagupta (628 CE): the Indian mathematician gave a general solution of quadratic equations, including negative and zero values.
  • Fact: the area picture of completing the square is the original proof. Algebra symbols came much later.

5Real-World Applications

  • Optimisation: a farmer who wants the largest pen for a fixed length of fence completes the square on the area formula.
  • Business: the best selling price is found from the vertex of a revenue or profit quadratic.
  • Physics: the highest point of a projectile and the time it reaches it come from the vertex.
  • Engineering: the shape of an arch or a reflector is described by a completed-square equation.
  • Computing: algorithms that find a minimum use the same idea, “the smallest value of a square is zero”.

7Classwork & Homework

Classwork

  1. Complete the square: x² + 8x.
    Answerx² + 8x = (x + 4)² − 16.
  2. Write x² − 2x − 5 in the form (x − h)² + k.
    Answer(x − 1)² − 1 − 5 = (x − 1)² − 6.
  3. Solve x² + 6x − 7 = 0 by completing the square.
    Answer(x + 3)² = 16, so x + 3 = ±4 and x = 1 or x = −7.
  4. Write 3x² − 12x + 7 in the form a(x − h)² + k.
    Answer3[(x − 2)² − 4] + 7 = 3(x − 2)² − 5.

Homework

  1. Write x² + 10x + 30 in completed-square form and state its minimum value.
    Answer(x + 5)² + 5. Minimum value 5 at x = −5.
  2. Solve x² − 6x + 2 = 0, giving exact answers.
    Answer(x − 3)² = 7, so x = 3 ± √{7}.
  3. Write −x² + 6x − 4 in the form −(x − h)² + k and state the maximum value.
    Answer−[(x − 3)² − 9] − 4 = −(x − 3)² + 5. Maximum value 5.
  4. Show that x² + x + 1 is always positive.
    Answerx² + x + 1 = (x + ⟦1|2⟧)² + ⟦3|4⟧. A square is at least 0, so the expression is at least ⟦3|4⟧ > 0.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [6 marks] Let f(x) = x² − 6x + 11.
(a) Write f(x) in the form (x − h)² + k. [3]
(b) Write down the coordinates of the vertex and the minimum value of f. [2]
(c) Hence explain why f(x) > 0 for all real x. [1]
Mark scheme(a) M1 (x − 3)²; M1 −9 + 11; A1 (x − 3)² + 2.
(b) A1 vertex (3, 2); A1 minimum value 2.
(c) R1 (x − 3)² ≥ 0, so f(x) ≥ 2 > 0.
Question 2 [7 marks] Solve 2x² − 12x + 7 = 0 by completing the square. Give your answers in the form 3 ± ⟦√{k}|2⟧.
Mark schemeM1 2(x² − 6x) + 7; M1 2[(x − 3)² − 9] + 7; A1 2(x − 3)² − 11 = 0; M1 (x − 3)² = ⟦11|2⟧; M1 x − 3 = ±√{⟦11|2⟧}; A1 x = 3 ± √{⟦11|2⟧}; A1 x = 3 ± ⟦√{22}|2⟧ (k = 22).

Paper 2 style (GDC allowed)

Question 3 [6 marks] A farmer uses 40 m of fencing to make a rectangular pen against a straight river. No fence is needed along the river. The width of the pen is x metres.
(a) Show that the area of the pen is A = 40x − 2x². [1]
(b) Write A in the form −2(x − h)² + k. [3]
(c) State the maximum area and the dimensions of the pen that give it. [2]
Mark scheme(a) A1 length = 40 − 2x, so A = x(40 − 2x) = 40x − 2x².
(b) M1 −2(x² − 20x); M1 −2[(x − 10)² − 100]; A1 A = −2(x − 10)² + 200.
(c) A1 maximum area 200 m²; A1 width 10 m and length 20 m.
