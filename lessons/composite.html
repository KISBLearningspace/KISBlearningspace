2Study Notes

Composite function: “g after f”.
(g ∘ f)(x) = g( f(x) )
Apply f first, then g.
Example 1. f(x) = 2x + 1 and g(x) = x². Find (g ∘ f)(x), (f ∘ g)(x), and evaluate both at x = 3.
  1. Meaning of the notation. (g ∘ f)(x) = g(f(x)): apply f first, then g.
  2. Find g ∘ f. Replace x in g by f(x): g(f(x)) = (2x + 1)².
  3. Find f ∘ g. Replace x in f by g(x): f(g(x)) = 2x² + 1.
  4. Evaluate at x = 3. (g ∘ f)(3): f(3) = 7, then g(7) = 49. (f ∘ g)(3): g(3) = 9, then f(9) = 2(9) + 1 = 19.
Answer: 49 and 19, so in general g ∘ f ≠ f ∘ g (the order matters).
Example 2 (domain). f(x) = x − 4 and g(x) = √{x}. Find (g ∘ f)(x) and its domain.
  1. Form the composite. (g ∘ f)(x) = g(x − 4) = √{x − 4}.
  2. The output of f must be allowed in g. g needs a number that is at least 0, so f(x) = x − 4 ≥ 0.
  3. Solve. x ≥ 4.
Answer: (g ∘ f)(x) = √{x − 4}, domain x ≥ 4.
Identity function: I(x) = x. It leaves every input unchanged.
Inverse function f−1: undoes f, so
f( f−1(x) ) = x  and  f−1( f(x) ) = x

Finding the inverse (swap and solve)

  • Write y = f(x).
  • Swap x and y.
  • Solve for y. This is f−1(x).
  • Swap the domain and range: the domain of f−1 is the range of f.
Example 3 (inverse of a linear function). f(x) = 2x + 3. Find f−1(x).
  1. Write y = f(x). y = 2x + 3.
  2. Swap x and y. x = 2y + 3.
  3. Solve for y. x − 3 = 2y, so y = ⟦x − 3|2⟧.
  4. Check. f( f−1(x) ) = 2·⟦x − 3|2⟧ + 3 = (x − 3) + 3 = x ✓
Answer: f−1(x) = ⟦x − 3|2⟧
Example 4 (inverse of a rational function). f(x) = ⟦x + 1|x − 2⟧, x ≠ 2. Find f−1(x).
  1. Swap x and y. x = ⟦y + 1|y − 2⟧.
  2. Clear the fraction. Multiply both sides by (y − 2): xy − 2x = y + 1.
  3. Collect the y terms on one side. xy − y = 2x + 1.
  4. Factorise out y. y(x − 1) = 2x + 1.
  5. Divide. y = ⟦2x + 1|x − 1⟧, with x ≠ 1.
  6. Check the domain. f has a horizontal asymptote y = 1, so 1 is not in the range of f. That matches x ≠ 1 for f−1.
Answer: f−1(x) = ⟦2x + 1|x − 1⟧, x ≠ 1

When does an inverse exist?

Only a one-to-one function has an inverse that is also a function. Use the horizontal line test: if any horizontal line meets the graph more than once, there is no inverse. We can restrict the domain: f(x) = x² is not one-to-one on ℝ, but f(x) = x², x ≥ 0 has inverse f−1(x) = √{x}.

Graph: the graph of f−1 is the reflection of the graph of f in the line y = x. If (a, b) is on f, then (b, a) is on f−1.

Example 5 (solving with composites). f(x) = 3x − 1, g(x) = x² + 2. Solve (f ∘ g)(x) = 20.
  1. Write the composite. (f ∘ g)(x) = f(g(x)) = 3(x² + 2) − 1.
  2. Set it equal to 20. 3(x² + 2) − 1 = 20.
  3. Expand. 3x² + 6 − 1 = 20, so 3x² + 5 = 20.
  4. Solve. 3x² = 15, x² = 5, so x = ±√{5}.
Answer: x = √{5} or x = −√{5}

Think: ① Is f ∘ g always the same as g ∘ f? Find a pair where it is. ② Why does f(x) = x² have no inverse on ℝ? ③ The function f(x) = ⟦1|x⟧ is its own inverse. What does its graph look like?

3History & Facts

  • Leibniz (1673): used the word “function” for quantities that depend on a curve; the idea of combining functions grew from there.
  • John Herschel (1813): introduced the notation f−1 for an inverse function, which we still use today.
  • Codes: encrypting a message is a function and decrypting it is the inverse. The Roman Caesar cipher shifts letters by a fixed amount, and the Arab scholar Al-Kindi (9th century) showed how to break such codes with frequency analysis.
  • Fact: f−1(x) does NOT mean ⟦1|f(x)⟧. The “−1” is a label for the inverse, not a power.

5Real-World Applications

  • Shopping: a 20% discount followed by 7% VAT is a composite of two functions.
  • Unit conversion: converting °C to °F, then °F to kelvin, composes two functions; the inverse converts back.
  • Cryptography: encrypt and decrypt are inverse functions.
  • Computing: “undo” commands reverse the last action.
  • Money: given the amount paid, an inverse function finds the original price.

7Classwork & Homework

Classwork

  1. f(x) = x + 2 and g(x) = 3x. Find (f ∘ g)(x) and (g ∘ f)(x).
    Answer(f ∘ g)(x) = 3x + 2; (g ∘ f)(x) = 3(x + 2) = 3x + 6.
  2. f(x) = x² and g(x) = x − 1. Find (f ∘ g)(4).
    Answerg(4) = 3, f(3) = 9.
  3. Find the inverse of f(x) = 5x − 2.
    Answerx = 5y − 2 → f−1(x) = ⟦x + 2|5⟧.
  4. Show that f(x) = 2x + 3 and g(x) = ⟦x − 3|2⟧ are inverses.
    Answerf(g(x)) = 2·⟦x − 3|2⟧ + 3 = x and g(f(x)) = ⟦2x + 3 − 3|2⟧ = x.

Homework

  1. f(x) = √{x} and g(x) = x − 9. Find (f ∘ g)(x) and its domain.
    Answer(f ∘ g)(x) = √{x − 9}; domain x ≥ 9.
  2. f(x) = ⟦2|x⟧ + 1, x ≠ 0. Find f−1(x).
    Answerx = ⟦2|y⟧ + 1 → ⟦2|y⟧ = x − 1 → f−1(x) = ⟦2|x − 1⟧, x ≠ 1.
  3. f(x) = x² − 4, x ≥ 0. Find f−1(x) and its domain.
    Answerx = y² − 4 → y = √{x + 4}; domain x ≥ −4 (the range of f).
  4. f(x) = 3x + 2 and g(x) = x − 5. Solve (g ∘ f)(x) = 10.
    Answer3x + 2 − 5 = 10 → 3x = 13 → x = ⟦13|3⟧.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [8 marks] Let f(x) = 2x − 3 and g(x) = x² + 1.
(a) Find (f ∘ g)(x). [2]
(b) Find (g ∘ f)(2). [2]
(c) Find f−1(x). [2]
(d) Solve f(x) = f−1(x). [2]
Mark scheme(a) M1 f(x² + 1) = 2(x² + 1) − 3; A1 2x² − 1.
(b) M1 f(2) = 1; A1 g(1) = 2.
(c) M1 x = 2y − 3; A1 f−1(x) = ⟦x + 3|2⟧.
(d) M1 2x − 3 = ⟦x + 3|2⟧ (or f(x) = x); A1 x = 3.

Paper 2 style (GDC allowed)

Question 2 [6 marks] Let f(x) = ⟦3x + 1|x − 2⟧, for x ≠ 2.
(a) Write down the equations of the vertical and horizontal asymptotes of the graph of f. [2]
(b) Find f−1(x). [3]
(c) Write down the domain of f−1. [1]
Mark scheme(a) A1 x = 2; A1 y = 3.
(b) M1 x = ⟦3y + 1|y − 2⟧; M1 xy − 2x = 3y + 1 → y(x − 3) = 2x + 1; A1 f−1(x) = ⟦2x + 1|x − 3⟧.
(c) A1 x ≠ 3 (the range of f).
Question 3 [5 marks] A shop gives a 20% discount, so the discounted price is D(p) = 0.8p. Then 7% VAT is added: V(p) = 1.07p, where p is the original price in baht.
(a) Find (V ∘ D)(p). [2]
(b) A customer pays 1712 baht. Find the original price. [3]
Mark scheme(a) M1 V(0.8p) = 1.07(0.8p); A1 0.856p.
(b) M1 0.856p = 1712; M1 p = ⟦1712|0.856⟧; A1 p = 2000 baht.
