2Study Notes

Series. A series is the sum of the terms of a sequence. Sₙ = u₁ + u₂ + … + uₙ.
Sum of an arithmetic series
Sₙ = ⟦n|2⟧(u₁ + uₙ) and Sₙ = ⟦n|2⟧(2u₁ + (n − 1)d)
Use the first form when you know the last term; use the second when you know d.
Why it works (Gauss). Write the sum forwards and backwards. Each pair adds to the same total (u₁ + uₙ), and there are n pairs, so 2Sₙ = n(u₁ + uₙ).
Sigma notation. Σ means “add up”. ∑ from k = 1 to n of f(k) means f(1) + f(2) + … + f(n). The numbers below and above show where to start and stop.
Finding a term from sums. For n ≥ 2: uₙ = Sₙ − Sₙ₋₁. Also u₁ = S₁.
KnowUse
u₁, uₙ, nSₙ = ⟦n|2⟧(u₁ + uₙ)
u₁, d, nSₙ = ⟦n|2⟧(2u₁ + (n − 1)d)

Example 1 (sum with last term). Find the sum of the first 10 terms of 3, 7, 11, …
  1. d = 4. u₁₀ = 3 + 9 × 4 = 39
  2. Use Sₙ = ⟦n|2⟧(u₁ + uₙ). S₁₀ = 5(3 + 39)
  3. Calculate. 210
Answer: S₁₀ = 210
Example 2 (Gauss). Find 1 + 2 + 3 + … + 100.
  1. u₁ = 1, u₁₀₀ = 100, n = 100. S = 50(1 + 100)
  2. Calculate. 5050
Answer: 5050
Example 3 (with d). Find S₁₂ for 40, 37, 34, …
  1. u₁ = 40, d = −3. S₁₂ = 6(80 + 11 × (−3))
  2. Calculate. 6(80 − 33) = 6 × 47 = 282
Answer: S₁₂ = 282
Example 4 (find n). How many terms of 2 + 5 + 8 + … are needed for a sum of 392?
  1. S = ⟦n|2⟧(2 × 2 + 3(n − 1)) = 392 ⟦n|2⟧(3n + 1) = 392
  2. Multiply out. 3n² + n − 784 = 0
  3. Solve. (3n + 49)(n − 16) = 0, n = 16 (n must be positive)
Answer: n = 16
Example 5 (sigma). Evaluate the sum of 3k + 2 for k = 1 to 20.
  1. First term (k = 1). 5
  2. Last term (k = 20). 62
  3. Number of terms. 20
  4. S = ⟦20|2⟧(5 + 62). 670
Answer: 670
Example 6 (two sums). S₅ = 55 and S₁₀ = 210 for an arithmetic series. Find u₁ and d.
  1. S₅. ⟦5|2⟧(2u₁ + 4d) = 55 → u₁ + 2d = 11
  2. S₁₀. 5(2u₁ + 9d) = 210 → 2u₁ + 9d = 42
  3. Substitute u₁ = 11 − 2d. 22 − 4d + 9d = 42, d = 4
  4. Then. u₁ = 3
Answer: u₁ = 3, d = 4
Example 7 (theatre). A theatre has 15 rows. The first row has 20 seats and each row has 2 more than the one before. How many seats are there in total?
  1. u₁₅ = 20 + 14 × 2. 48
  2. S₁₅ = ⟦15|2⟧(20 + 48). 510
Answer: 510 seats
Example 8 (uₙ from Sₙ). Sₙ = n² + 2n. Find uₙ.
  1. Sₙ₋₁. (n − 1)² + 2(n − 1) = n² − 1
  2. uₙ = Sₙ − Sₙ₋₁. n² + 2n − (n² − 1) = 2n + 1
  3. Check u₁. S₁ = 3 = 2(1) + 1 ✓
Answer: uₙ = 2n + 1
Common mistakes.
① Using the wrong formula (u₁ + uₙ needs the last term).
② Forgetting the ⟦n|2⟧.
③ Counting the number of terms wrongly in sigma notation (k = 1 to 20 gives 20 terms).
④ Keeping a negative solution for n.
⑤ Using uₙ = Sₙ − Sₙ₋₁ for n = 1 (use u₁ = S₁).

3History & Facts

  • Carl Friedrich Gauss (about 1787): as a school pupil he found 1 + 2 + … + 100 by pairing numbers.
  • Aryabhata (about 499 CE): gave rules for summing arithmetic progressions.
  • Today: series are used to find totals in finance, engineering and computing.

5Real-World Applications

  • Savings plans: saving a growing amount each month.
  • Construction: a stack of logs or pipes with one more in each row.
  • Sports training: total distance when the weekly distance increases by a fixed amount.
  • Theatre and stadium seating: total number of seats.
  • Loan repayments: payments that rise by a fixed amount.

    AnswerS = 25 × 51 = 1275

Homework

  1. Find S₁₅ for 6, 10, 14, …
    AnswerS₁₅ = ⟦15|2⟧(12 + 56) = 510
  2. How many terms of 4 + 7 + 10 + … give a sum of 286?
    Answer⟦n|2⟧(3n + 5) = 286, 3n² + 5n − 572 = 0, (3n + 44)(n − 13) = 0, n = 13
  3. S₄ = 36 and S₆ = 72. Find u₁ and d.
    Answer2u₁ + 3d = 18; 2u₁ + 5d = 24; d = 3, u₁ = 4.5
  4. Sₙ = 3n² + n. Find uₙ.
    Answeruₙ = 6n − 2

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. No calculator. Open “Mark scheme” only after trying.

Paper 1 style

Question 1 [3 marks] Find the sum of the first 25 terms of the arithmetic sequence 6, 11, 16, … [3]
Mark schemeA1 d = 5; M1 S₂₅ = ⟦25|2⟧(12 + 24 × 5); A1 1650.
Question 2 [4 marks] An arithmetic sequence has u₁ = 8 and S₁₀ = 215. Find d. [4]
Mark schemeM1 S₁₀ = 5(16 + 9d); A1 215 = 80 + 45d; A1 45d = 135; A1 d = 3.
Question 3 [4 marks] Evaluate ∑ from k = 1 to 30 of (4k − 1). [4]
Mark schemeA1 u₁ = 3; A1 u₃₀ = 119; M1 ⟦30|2⟧(3 + 119); A1 1830.

Paper 2 style

Question 4 [8 marks] Mia saves $20 in week 1 and increases her saving by $4 each week. (a) How much does she save in week 15? [2] (b) How much has she saved in total after 15 weeks? [2] (c) After how many weeks has she saved more than $1000 in total? [3] (d) State one assumption. [1]
Mark scheme(a) M1 20 + 14 × 4; A1 $76. (b) M1 ⟦15|2⟧(20 + 76); A1 $720. (c) M1 Sₙ = n(2n + 18) > 1000; A1 S₁₈ = 972 (too small); A1 S₁₉ = 1064, so n = 19. (d) R1 she keeps increasing by exactly $4 every week.
