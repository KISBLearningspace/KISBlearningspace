2Study Notes

Trick 1: Telescoping. ⟦1|n(n + 1)⟧ = ⟦1|n⟧ − ⟦1|n + 1⟧. In a sum the middle terms cancel and only the first and last remain. Similarly ⟦1|n(n + 2)⟧ = ⟦1|2⟧(⟦1|n⟧ − ⟦1|n + 2⟧).
Trick 2: Rationalise. ⟦1|√{n} + √{n + 1}⟧ = √{n + 1} − √{n}. Multiply the top and bottom by √{n + 1} − √{n}. The sum telescopes.
Trick 3: Nested fractions. Start at the bottom and work up. For a function applied again and again, compute 3 or 4 steps. A cycle usually appears. Then use the remainder.
Trick 4: Floor function. ⌊x⌋ is the whole-number part. For ⌊√{n}⌋: the value k appears for n = k², …, (k + 1)² − 1, which is 2k + 1 values. Count by blocks.
Trick 5: Product of 2^(2^k) + 1. Multiply by (2 − 1) = 1 and use (a − b)(a + b) = a² − b² again and again: (2 + 1)(2² + 1)(2⁴ + 1) = 2⁸ − 1.

Example 1 [Level 2] (telescoping). Find ⟦1|1 × 2⟧ + ⟦1|2 × 3⟧ + … + ⟦1|49 × 50⟧.
  1. Each term is ⟦1|n⟧ − ⟦1|n + 1⟧. (1 − ⟦1|2⟧) + (⟦1|2⟧ − ⟦1|3⟧) + … + (⟦1|49⟧ − ⟦1|50⟧)
  2. Everything in the middle cancels. 1 − ⟦1|50⟧
Answer: ⟦49|50⟧
Example 2 [Level 3] (step 2). Find ⟦1|1 × 3⟧ + ⟦1|3 × 5⟧ + … + ⟦1|19 × 21⟧.
  1. ⟦1|(2k − 1)(2k + 1)⟧ = ⟦1|2⟧(⟦1|2k − 1⟧ − ⟦1|2k + 1⟧). Sum = ⟦1|2⟧(1 − ⟦1|21⟧)
  2. Simplify. ⟦1|2⟧ × ⟦20|21⟧
Answer: ⟦10|21⟧
Example 3 [Level 3] (roots). Find ⟦1|√{1} + √{2}⟧ + ⟦1|√{2} + √{3}⟧ + … + ⟦1|√{99} + √{100}⟧.
  1. Each term is √{n + 1} − √{n}. (√{2} − 1) + (√{3} − √{2}) + …
  2. Only the ends are left. √{100} − 1 = 9
Answer: 9
Example 4 [Level 2] (nested fraction). Evaluate 2 + ⟦1|3 + ⟦1|4⟧⟧.
  1. Bottom first: 3 + ⟦1|4⟧. ⟦13|4⟧
  2. Then ⟦1|⟦13|4⟧⟧. ⟦4|13⟧
  3. 2 + ⟦4|13⟧. ⟦30|13⟧
Answer: ⟦30|13⟧
Example 5 [Level 3] (cycle). f(x) = ⟦1|1 − x⟧. Find f applied 2026 times to the number 2.
  1. f(2) = −1, f(−1) = ⟦1|2⟧, f(⟦1|2⟧) = 2. The cycle has length 3: 2, −1, ⟦1|2⟧
  2. 2026 = 3 × 675 + 1. The result is the first number of the cycle after 2: −1
Answer: −1
Example 6 [Level 3] (floor). Find ⌊√{1}⌋ + ⌊√{2}⌋ + … + ⌊√{35}⌋.
  1. Value 1 for n = 1 to 3 (3 terms). Value 2 for n = 4 to 8 (5 terms). Value 3 for n = 9 to 15 (7 terms). Value 4 for n = 16 to 24 (9 terms). Value 5 for n = 25 to 35 (11 terms). 3 × 1 + 5 × 2 + 7 × 3 + 9 × 4 + 11 × 5
  2. Add. 3 + 10 + 21 + 36 + 55
Answer: 125
Example 7 [Level 2] (product). Find (2 + 1)(2² + 1)(2⁴ + 1)(2⁸ + 1).
  1. Multiply and divide by (2 − 1) = 1 and use differences of squares. (2 − 1)(2 + 1) = 2² − 1; (2² − 1)(2² + 1) = 2⁴ − 1; and so on
  2. The chain ends at 2¹⁶ − 1. 65 535
Answer: 65 535
Common mistakes.
① Cancelling the wrong terms: write the first three and last three terms to see which survive.
② Forgetting the factor ⟦1|2⟧ in ⟦1|n(n + 2)⟧.
③ Not counting the last block in a floor sum (it may be incomplete).
④ Computing a nested fraction from the top instead of the bottom.
⑤ Assuming a cycle after only two steps: confirm that the first value returns.

3History & Facts

  • Leibniz (1670s): found that the sum of ⟦1|n(n + 1)⟧ is 1, using the idea of cancelling differences.
  • Euler (1700s): used telescoping and clever rewriting to sum many series.
  • Continued fractions: studied since Greek times; they give very good approximations to numbers such as π.

5Real-World Applications

  • Physics: cancelling differences gives total change (net displacement).
  • Computing: loops that count with floor and integer division.
  • Finance: repeated discounting is a nested fraction.
  • Engineering: circuits made of repeated resistors give nested fractions.
  • Number theory: continued fractions approximate irrational numbers.

10Exam-style Questions

Original questions in the style of a maths olympiad. Section A = 3 marks, Section B = 4 marks, Section C = 6 marks (write the numerical answer). Open “Solution” only after trying.

Section A

Question 1 [3 marks] ⟦1|1 × 2⟧ + ⟦1|2 × 3⟧ + … + ⟦1|19 × 20⟧ = (A) ⟦18|19⟧ (B) ⟦19|20⟧ (C) ⟦20|21⟧ (D) 1 (E) ⟦19|21⟧
Solution(B) ⟦19|20⟧. The sum telescopes to 1 − ⟦1|20⟧.
Question 2 [3 marks] (2 + 1)(2² + 1)(2⁴ + 1) = (A) 127 (B) 191 (C) 255 (D) 257 (E) 511
Solution(C) 255 = 3 × 5 × 17 = 2⁸ − 1.

Section B

Question 3 [4 marks] ⟦1|√{3} + √{4}⟧ + ⟦1|√{4} + √{5}⟧ + … + ⟦1|√{24} + √{25}⟧ = (A) 4 (B) 5 − √{3} (C) 5 (D) 4 + √{3} (E) √{3}
Solution(B) 5 − √{3}. Each term is √{n + 1} − √{n}, so the sum is √{25} − √{3}.

Section C

Question 4 [6 marks] Find ⌊√{1}⌋ + ⌊√{2}⌋ + … + ⌊√{80}⌋.
Solution444. The value k appears 2k + 1 times for k = 1 to 8 (n = 1 to 80 is exactly 8 full blocks). The sum is the sum of k(2k + 1) for k = 1, …, 8 = 2 × 204 + 36 = 444.
