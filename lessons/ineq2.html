2Study Notes

Inequality. A statement that compares two expressions using one of four symbols:
< “is less than”   > “is greater than”   ≤ “is less than or equal to”   ≥ “is greater than or equal to”.
Strict (<, >) does not include the end value; inclusive (≤, ≥) does.
Solution set. An equation like 2x = 6 has one solution. An inequality like 2x < 6 has infinitely many: every number x that makes it true. We write the solution set in four ways:
WordsInequalityNumber lineInterval notation
x is greater than 3x > 3open circle ○ at 3, line to the right(3, ∞)
x is at most 5x ≤ 5filled circle ● at 5, line to the left(−∞, 5]
x is between −2 (not included) and 4 (included)−2 < x ≤ 4○ at −2, ● at 4, line between(−2, 4]
x is less than −1 or greater than 2x < −1 or x > 2two rays, ○ at both ends(−∞, −1) ∪ (2, ∞)

In interval notation, a round bracket ( ) means the end value is not included, a square bracket [ ] means it is included, and ∞ always gets a round bracket. Set notation: {x | x > 3}, read “the set of all x such that x is greater than 3”.

The rules for solving. Solve like an equation, with one important difference:
① Adding or subtracting the same number on both sides keeps the sign.
② Multiplying or dividing both sides by a positive number keeps the sign.
③ Multiplying or dividing both sides by a negative number reverses the sign (< becomes >, ≤ becomes ≥).
Why does it flip? We know 2 < 5. Multiply both sides by −1: we get −2 and −5. On the number line −5 is to the left of −2, so −2 > −5. Multiplying by a negative reflects the number line, so the order reverses.
Example 1 (words to symbols). A lift can carry at most 8 people. Write this as an inequality and show it on a number line and in interval notation.
  1. Choose a variable. Let n be the number of people.
  2. Translate “at most”. At most 8 means 8 or fewer: n ≤ 8.
  3. Add the context. n cannot be negative, and people come in whole numbers, so n = 0, 1, 2, …, 8.
  4. Number line. A filled circle at 8 (8 is allowed) with the line going left.
  5. Interval notation (for a real variable x ≤ 8). (−∞, 8].
Answer: n ≤ 8; the possible values are 0, 1, …, 8.
Example 2 (a two-step inequality). Solve 3x − 5 ≤ 10.
  1. Goal. Get x alone on one side.
  2. Undo the subtraction: add 5 to both sides. 3x ≤ 15.
  3. Undo the multiplication: divide by 3 (positive, so the sign stays). x ≤ 5.
  4. Check with a test value. Try x = 0, which is in the solution: 3(0) − 5 = −5 ≤ 10 ✓. Try x = 6, which is not: 3(6) − 5 = 13, not ≤ 10 ✓.
Answer: x ≤ 5, that is, (−∞, 5].
Example 3 (variable on both sides). Solve 5x + 2 > 2x + 14.
  1. Collect the x terms on one side: subtract 2x. 3x + 2 > 14.
  2. Collect the numbers on the other side: subtract 2. 3x > 12.
  3. Divide by 3 (positive). x > 4.
  4. Check. x = 5: left 27, right 24, and 27 > 24 ✓. x = 4 gives 22 and 22, which are equal, so 4 is not included ✓.
Answer: x > 4, that is, (4, ∞).
Example 4 (a negative coefficient: the sign flips). Solve 7 − 2x < 1.
  1. Subtract 7 from both sides. −2x < −6.
  2. Divide by −2. This is negative, so reverse the sign. x > 3.
  3. Check. x = 4: 7 − 8 = −1 < 1 ✓. x = 0: 7 − 0 = 7, not < 1 ✓.
  4. Alternative way (avoids dividing by a negative). Add 2x to both sides: 7 < 1 + 2x, so 6 < 2x and 3 < x, which says x > 3. The same answer.
Answer: x > 3, that is, (3, ∞).
Example 5 (brackets and fractions). Solve (a) 2(x − 3) < 4x + 2 and (b) ⟦x + 1|3⟧ ≥ 2.
  1. (a) Expand the bracket. 2x − 6 < 4x + 2.
  2. (a) Collect terms: subtract 4x and add 6. −2x < 8.
  3. (a) Divide by −2 and reverse the sign. x > −4.
  4. (b) Clear the fraction: multiply both sides by 3 (positive). x + 1 ≥ 6.
  5. (b) Subtract 1. x ≥ 5.
Answer: (a) x > −4; (b) x ≥ 5.
Compound inequalities. Two conditions on x at once.
• “and” (between): a < x < b, one connected piece. Solve all three parts at the same time.
• “or”: two separate pieces. Solve each inequality and join the answers with ∪ (union).
Example 6 (a “between” inequality). Solve −3 < 2x + 1 ≤ 9.
  1. Do the same step to all three parts. Subtract 1. −4 < 2x ≤ 8.
  2. Divide all three parts by 2. −2 < x ≤ 4.
  3. Show it. ○ at −2, ● at 4, with the line between them.
Answer: −2 < x ≤ 4, that is, (−2, 4].
Example 7 (an “or” inequality). Solve 2x − 1 < −5 or 3x > 12.
  1. Solve the first inequality. 2x < −4, so x < −2.
  2. Solve the second inequality. x > 4.
  3. Combine with “or”. x is in either piece.
Answer: x < −2 or x > 4, that is, (−∞, −2) ∪ (4, ∞).
Quadratic inequalities. Do not divide or take square roots as for equations. Use the graph of the quadratic:
① Move everything to one side so the other side is 0.
② Solve the related equation to find the roots (the x-intercepts).
③ Sketch the parabola (upwards if the coefficient of x² is positive).
④ Read the region: “> 0” means above the x-axis, “< 0” means below the x-axis.
⑤ Write the answer using the roots as end values.
Example 8 (≤ 0: between the roots). Solve x² − 5x + 6 ≤ 0.
  1. The right side is already 0. Find the roots. x² − 5x + 6 = (x − 2)(x − 3) = 0, so x = 2 or x = 3.
  2. Sketch. The coefficient of x² is positive, so the parabola opens upwards and cuts the x-axis at 2 and 3.
  3. Read the region. We need y ≤ 0, that is, on or below the x-axis. That is between the roots, and including them because of ≤.
  4. Check. x = 2.5: 6.25 − 12.5 + 6 = −0.25 ≤ 0 ✓. x = 0: 6, not ≤ 0 ✓.
Answer: 2 ≤ x ≤ 3, that is, [2, 3].
Example 9 (> 0: outside the roots). Solve x² > 2x + 8.
  1. Move everything to one side. x² − 2x − 8 > 0.
  2. Factorise to find the roots. (x − 4)(x + 2) = 0, so x = 4 or x = −2.
  3. Sketch an upward parabola through −2 and 4. It is above the x-axis to the left of −2 and to the right of 4.
  4. Read the region for > 0. The two outer pieces. The end values are not included (strict).
  5. Check. x = 0 lies between the roots: 0 > 8 is false ✓. x = 5: 25 > 18 ✓.
Answer: x < −2 or x > 4, that is, (−∞, −2) ∪ (4, ∞).
Example 10 (no real roots). Solve (a) x² + 2x + 5 > 0 and (b) x² + 2x + 5 < 0.
  1. Check the discriminant. Δ = b² − 4ac = 4 − 20 = −16 < 0, so the parabola never touches the x-axis.
  2. The parabola opens upwards, so it is always above the x-axis. Another way: x² + 2x + 5 = (x + 1)² + 4 ≥ 4 > 0.
  3. (a) It is positive for every real x.
  4. (b) It is never negative.
Answer: (a) all real x, that is, (−∞, ∞); (b) no solution.
Absolute value (extension). |x − a| is the distance from x to a. So
|x − a| < b means a − b < x < a + b (within distance b), and
|x − a| > b means x < a − b or x > a + b (further than b).
Example 11 (absolute value). Solve (a) |x − 3| < 5 and (b) |2x + 1| ≥ 7.
  1. (a) Rewrite as a “between” inequality. −5 < x − 3 < 5.
  2. (a) Add 3 to all three parts. −2 < x < 8.
  3. (b) Rewrite as two cases. 2x + 1 ≥ 7 or 2x + 1 ≤ −7.
  4. (b) Solve each. 2x ≥ 6 gives x ≥ 3. 2x ≤ −8 gives x ≤ −4.
Answer: (a) −2 < x < 8; (b) x ≤ −4 or x ≥ 3.
Example 12 (rational inequality, extension). Solve ⟦x + 1|x − 2⟧ > 0.
  1. Do not multiply by (x − 2): it can be positive or negative. Use a sign table instead.
  2. Find the critical values. The numerator is 0 at x = −1; the denominator is 0 at x = 2 (x cannot equal 2).
  3. Test each region. x < −1: (−)/(−) = + . −1 < x < 2: (+)/(−) = −. x > 2: (+)/(+) = +.
  4. Choose where it is positive (strict, so −1 is not included). Outer regions.
Answer: x < −1 or x > 2.
Example 13 (a word problem). A taxi charges 40 baht plus 12 baht per km. Bahar has 200 baht. How far can she travel?
  1. Define a variable. Let d be the distance in km.
  2. Write the inequality: cost ≤ money. 40 + 12d ≤ 200.
  3. Subtract 40. 12d ≤ 160.
  4. Divide by 12. d ≤ ⟦160|12⟧ = ⟦40|3⟧ ≈ 13.3.
  5. Interpret. The distance cannot be negative, so 0 ≤ d ≤ 13.3.
Answer: She can travel up to about 13.3 km.
Common mistakes.
① Forgetting to reverse the sign when multiplying or dividing by a negative number.
② Writing 3 < x < 2 (impossible): in a compound inequality the smaller number goes on the left.
③ Multiplying both sides by an expression with x in it (the sign may be negative).
④ Solving x² > 4 as x > 2 only: the correct answer is x < −2 or x > 2.
⑤ Using a closed circle for < or >, and an open circle for ≤ or ≥.
Always check with a test value.

3History & Facts

  • Thomas Harriot (1631): the symbols < and > first appeared in his book on algebra, published after his death.
  • Pierre Bouguer (1734): introduced ≤ and ≥ in a form close to the signs we use today.
  • Linear programming (1940s): systems of inequalities are used to find the best way to use limited resources, and were first used on a large scale for military planning and then in industry.
  • Fact: the study of inequalities is the key tool for proving that approximations are accurate enough, for example in calculus and in numerical computing.

5Real-World Applications

  • Budgets and limits: spend at most 5000 baht, or carry at most 20 kg.
  • Safety and health: a safe dose of a medicine lies between a minimum and a maximum.
  • Business: a business makes a profit when revenue is greater than cost.
  • Engineering: measurements must lie within a tolerance, such as |x − 250| < 2 g.
  • Computer science and AI: optimisation problems are solved with systems of inequalities (linear programming).

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style

Question 1 [4 marks] Solve the inequality 3x − 7 ≥ 5x + 1. Write your answer in interval notation.
Mark schemeM1 collect terms, for example −8 ≥ 2x; M1 divide by a positive number (not by −2 unless the sign is reversed); A1 x ≤ −4; A1 (−∞, −4].
Question 2 [5 marks] Solve x² − x − 12 < 0.
Mark schemeM1 factorise or use the formula: (x − 4)(x + 3); A1 roots x = 4 and x = −3; M1 sketch or sign diagram with an upward parabola; A1 below the axis between the roots; A1 −3 < x < 4.
Question 3 [4 marks] (a) Solve |x − 2| ≤ 3. [2] (b) Write the solution set as an interval. [1] (c) Does x = 5.5 satisfy the inequality? Explain. [1]
Mark scheme(a) M1 −3 ≤ x − 2 ≤ 3; A1 −1 ≤ x ≤ 5. (b) A1 [−1, 5]. (c) R1 No, 5.5 > 5, which is outside the interval.

Paper 2 style

Question 4 [9 marks] A company’s weekly profit P (in thousand baht) when it makes x hundred items is P = −x² + 12x − 20.
(a) Solve P > 0, that is, find when the company makes a profit. [4]
(b) Find the value of x that gives the greatest profit, and the greatest profit. [3]
(c) The company needs a profit of at least 12. Find the range of x. [2]
Mark scheme(a) M1 solve −x² + 12x − 20 = 0, that is, x² − 12x + 20 = 0; A1 x = 2 and x = 10; M1 sketch (the parabola opens downwards); A1 2 < x < 10.
(b) M1 vertex at x = −⟦b|2a⟧ = 6 (or the midpoint of the roots); A1 x = 6; A1 P = −36 + 72 − 20 = 16 (thousand baht).
(c) M1 −x² + 12x − 20 ≥ 12, so x² − 12x + 32 ≤ 0, which is (x − 4)(x − 8) ≤ 0; A1 4 ≤ x ≤ 8.
