Guiding questions

  • What happens to ⟦1|x⟧ when x is very large, and when x is very close to zero?
  • How can one fraction be rewritten as a transformation of ⟦1|x⟧?
  • Why is a value of x excluded from the domain, and what does this look like on the graph?

Learning outcomes

  • State the domain and range of the reciprocal function and sketch its graph.
  • Find the vertical and horizontal asymptotes of f(x) = ⟦ax + b|cx + d⟧.
  • Find the intercepts, sketch the graph and state the domain and range.
  • Rewrite ⟦ax + b|cx + d⟧ as a transformation of ⟦1|x⟧.
  • Solve equations involving rational functions and find the inverse function.

2Study Notes

Rational function: a function R(x) = ⟦f(x)|g(x)⟧ where f and g are polynomials. Its domain is all real numbers except the zeros of g(x).
Reciprocal function
f(x) = ⟦1|x⟧,   x ≠ 0
The graph has two branches (a hyperbola). The vertical asymptote is x = 0 and the horizontal asymptote is y = 0. Domain x ≠ 0, range y ≠ 0. The graph is symmetric about the line y = x, so f is self-inverse: f⁻¹(x) = ⟦1|x⟧.
The form
f(x) = ⟦ax + b|cx + d⟧  (c ≠ 0)
Vertical asymptote x = −⟦d|c⟧. Horizontal asymptote y = ⟦a|c⟧. x-intercept at x = −⟦b|a⟧ (the numerator is 0). y-intercept at y = ⟦b|d⟧ (put x = 0). Domain x ≠ −⟦d|c⟧, range y ≠ ⟦a|c⟧.
Example 1. f(x) = ⟦3|x − 2⟧ + 1. Find the asymptotes, the intercepts, and write f as one fraction.
  1. Vertical asymptote. The denominator is 0 when x = 2, so x = 2.
  2. Horizontal asymptote. As x gets large, ⟦3|x − 2⟧ → 0, so y → 1. The line is y = 1.
  3. Transformations of y = ⟦1|x⟧. Vertical stretch with scale factor 3, then 2 right and 1 up.
  4. x-intercept: put f(x) = 0. ⟦3|x − 2⟧ = −1, so x − 2 = −3 and x = −1.
  5. y-intercept: put x = 0. f(0) = ⟦3|−2⟧ + 1 = −⟦3|2⟧ + 1 = −⟦1|2⟧.
  6. One fraction. Write 1 = ⟦x − 2|x − 2⟧: f(x) = ⟦3 + x − 2|x − 2⟧ = ⟦x + 1|x − 2⟧.
Answer: Asymptotes x = 2 and y = 1; intercepts (−1, 0) and (0, −⟦1|2⟧).
Example 2. f(x) = ⟦2x + 1|x − 3⟧. Find the asymptotes, intercepts, domain and range.
  1. Vertical asymptote: denominator = 0. x − 3 = 0, so x = 3.
  2. Horizontal asymptote: compare the x coefficients. As x is large, f ≈ ⟦2x|x⟧ = 2, so y = 2.
  3. x-intercept: numerator = 0. 2x + 1 = 0, so (−⟦1|2⟧, 0).
  4. y-intercept: put x = 0. f(0) = ⟦1|−3⟧ = −⟦1|3⟧, so (0, −⟦1|3⟧).
  5. Domain and range. x cannot be 3, and y never equals the horizontal asymptote 2.
Answer: Asymptotes x = 3 and y = 2; domain x ≠ 3; range y ≠ 2.
Example 3 (division form). Write ⟦2x + 1|x − 3⟧ in the form a + ⟦b|x − 3⟧.
  1. Make the numerator contain the denominator. 2x + 1 = 2(x − 3) + 6 + 1 = 2(x − 3) + 7.
  2. Split the fraction. ⟦2(x − 3) + 7|x − 3⟧ = ⟦2(x − 3)|x − 3⟧ + ⟦7|x − 3⟧.
  3. Simplify. = 2 + ⟦7|x − 3⟧.
  4. Interpret. The graph is y = ⟦1|x⟧ stretched vertically by 7, then moved 3 right and 2 up. The asymptotes x = 3 and y = 2 can be read straight from this form.
Answer: 2 + ⟦7|x − 3⟧
Example 4 (solving). Solve ⟦2x + 1|x − 3⟧ = 5, x ≠ 3.
  1. Multiply both sides by (x − 3). 2x + 1 = 5(x − 3).
  2. Expand. 2x + 1 = 5x − 15.
  3. Collect terms. 16 = 3x.
  4. Solve. x = ⟦16|3⟧. This is not 3, so it is allowed.
  5. Check. ⟦2(16/3) + 1|16/3 − 3⟧ = ⟦35/3|7/3⟧ = 5 ✓
Answer: x = ⟦16|3⟧
Example 5 (inverse). Find the inverse of y = ⟦2x + 1|x − 3⟧.
  1. Swap x and y. x = ⟦2y + 1|y − 3⟧.
  2. Clear the fraction. x(y − 3) = 2y + 1, so xy − 3x = 2y + 1.
  3. Collect the y terms. xy − 2y = 3x + 1.
  4. Factorise. y(x − 2) = 3x + 1.
  5. Divide. y = ⟦3x + 1|x − 2⟧.
Answer: f⁻¹(x) = ⟦3x + 1|x − 2⟧. The domain of f⁻¹ (x ≠ 2) matches the range of f (y ≠ 2).
Example 6 (modelling). A club hires a hall for a fixed fee of 200 plus 15 per member. Find the average cost per member for n members, and its value for n = 40.
  1. Total cost. 15n + 200.
  2. Average cost = total ÷ n. C(n) = ⟦15n + 200|n⟧ = ⟦15n|n⟧ + ⟦200|n⟧ = 15 + ⟦200|n⟧.
  3. Evaluate at n = 40. C = 15 + ⟦200|40⟧ = 15 + 5 = 20.
  4. Asymptote. As n grows, ⟦200|n⟧ → 0, so C approaches 15 but never reaches it.
Answer: C(n) = 15 + ⟦200|n⟧; C(40) = 20; the horizontal asymptote C = 15.
HL extension. For R(x) = ⟦f(x)|g(x)⟧: if the degree of f is less than the degree of g, the horizontal asymptote is y = 0; if the degrees are equal, it is the ratio of the leading coefficients. Vertical asymptotes occur at zeros of g that are not also zeros of f. Examples from the HL book: p(x) = ⟦1|x − 5⟧ (domain x ≠ 5), q(x) = ⟦x + 2|(x + 3)(x − 1)⟧ (domain x ≠ −3, 1), r(x) = ⟦x|x² + 1⟧ (domain: all real numbers, since x² + 1 is never 0).

Technology (GDC / Desmos)

Graph the function and check the asymptotes by zooming. On many GDCs the graph shows a false vertical line at the asymptote, so do not include it in a sketch. Use the intersection tool to solve f(x) = k.

Think: ① Why can the graph never cross the vertical asymptote? ② Can a graph cross its horizontal asymptote? Why does it get closer and closer for large x? ③ What does it mean when ad = bc in ⟦ax + b|cx + d⟧?

3History & Facts

  • Apollonius (about 200 BCE): studied the hyperbola, and the word “asymptote” comes from the Greek asymptotos, “not falling together”.
  • Egyptian scribes (about 1650 BCE): the Rhind papyrus writes fractions as sums of reciprocals (unit fractions) such as ⟦1|2⟧ + ⟦1|6⟧.
  • Robert Boyle (1662): found that the pressure of a gas is proportional to ⟦1|V⟧ when the temperature is fixed, an early physical use of the reciprocal function.
  • Fact: the lens equation ⟦1|f⟧ = ⟦1|u⟧ + ⟦1|v⟧ in physics is a rational relationship used to design cameras and glasses.

5Real-World Applications

  • Physics: Boyle’s law (pressure ∝ ⟦1|volume⟧), Ohm’s law (current = ⟦V|R⟧) and the lens equation are all reciprocal or rational relationships.
  • Travel: time = ⟦distance|speed⟧ is a reciprocal function of speed. Doubling the speed halves the time.
  • Business: average cost per unit = ⟦fixed cost + variable cost|n⟧ approaches the variable cost as n grows.
  • Chemistry and medicine: the concentration of a solution after diluting with x litres of water is a rational function of x.
  • Electronics: the resistance of two resistors in parallel uses reciprocals.

6IB Links: TOK, International-mindedness & ATL

  • TOK: an asymptote is a line the graph approaches but never reaches. How can mathematics talk about “infinity” and “approaching” without ever getting there?
  • International-mindedness: Egyptian scribes worked with reciprocals of whole numbers 3500 years ago, while Greek mathematicians gave the hyperbola its name. How do different cultures represent fractions?
  • ATL: thinking (rewrite a fraction as a transformation), communication (state asymptotes as equations, not just numbers).

7Classwork & Homework

Classwork

  1. State the domain and the range of f(x) = ⟦1|x⟧.
    AnswerDomain x ≠ 0; range y ≠ 0.
  2. For y = ⟦x + 1|x − 2⟧ find the asymptotes and the intercepts.
    AnswerVertical asymptote x = 2; horizontal asymptote y = 1; x-intercept (−1, 0); y-intercept (0, −⟦1|2⟧).
  3. Solve ⟦4|x + 1⟧ = 2.
    Answer4 = 2(x + 1), so x = 1.
  4. Describe how y = ⟦3|x − 2⟧ + 1 comes from y = ⟦1|x⟧.
    AnswerVertical stretch with scale factor 3, then a translation 2 units right and 1 unit up.

Homework

  1. Find the inverse of f(x) = ⟦2x + 1|x − 3⟧.
    Answerf⁻¹(x) = ⟦3x + 1|x − 2⟧.
  2. Show that ⟦2x + 1|x − 3⟧ = 2 + ⟦7|x − 3⟧ and state the asymptotes.
    Answer⟦2(x − 3) + 7|x − 3⟧ = 2 + ⟦7|x − 3⟧. Asymptotes x = 3 and y = 2.
  3. Solve ⟦3x − 2|x + 1⟧ = 1.
    Answer3x − 2 = x + 1, so x = ⟦3|2⟧.
  4. The average cost per member is C(n) = ⟦15n + 200|n⟧. Find n when C(n) = 20.
    Answer15n + 200 = 20n, so 5n = 200 and n = 40.

10Exam-style Questions

Marks: M = method, A = accuracy, R = reasoning. Open “Mark scheme” only after trying.

Paper 1 style (no calculator)

Question 1 [7 marks] Let f(x) = ⟦2x + 1|x − 3⟧, for x ≠ 3.
(a) Write down the equations of the vertical and horizontal asymptotes. [2]
(b) Find the x-intercept and the y-intercept of the graph of f. [2]
(c) Solve f(x) = 5. [3]
Mark scheme(a) A1 x = 3; A1 y = 2.
(b) A1 (−⟦1|2⟧, 0); A1 (0, −⟦1|3⟧).
(c) M1 2x + 1 = 5(x − 3); A1 2x + 1 = 5x − 15; A1 x = ⟦16|3⟧.
Question 2 [6 marks] Let g(x) = ⟦3x − 2|x + 1⟧, for x ≠ −1.
(a) Show that g(x) = 3 − ⟦5|x + 1⟧. [2]
(b) Describe the transformations that map the graph of y = ⟦1|x⟧ onto the graph of g. [3]
(c) Write down the range of g. [1]
Mark scheme(a) M1 ⟦3(x + 1) − 5|x + 1⟧; A1 = 3 − ⟦5|x + 1⟧.
(b) A1 translation 1 unit left; A1 vertical stretch with scale factor 5 and reflection in the x-axis; A1 translation 3 units up.
(c) A1 y ≠ 3.

Paper 2 style (GDC allowed)

Question 3 [6 marks] A club hires a hall for a fixed fee of 200, plus 15 for each member who attends, where all amounts are in hundreds of baht. The average cost per member is C(n) = ⟦15n + 200|n⟧, for n ≥ 1.
(a) Find the average cost when 40 members attend. [2]
(b) Find the smallest number of members for which the average cost is at most 18. [2]
(c) Write down the equation of the horizontal asymptote of the graph of C and explain what it means in this context. [2]
Mark scheme(a) M1 C(40) = ⟦15(40) + 200|40⟧; A1 20.
(b) M1 ⟦15n + 200|n⟧ ≤ 18, so 200 ≤ 3n (or use the GDC); A1 n ≥ 66.7, so n = 67.
(c) A1 C = 15; A1 the average cost per member gets closer to 15 as more members attend but never reaches it.
