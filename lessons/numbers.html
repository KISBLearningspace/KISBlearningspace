2Study Notes

IB notation: ℕ = {0, 1, 2, 3, …} (the IB includes 0; some books start at 1) · ℤ = {…, −2, −1, 0, 1, 2, …} · ℚ = all numbers ⟦p|q⟧ with p, q ∈ ℤ, q ≠ 0 · ℝ = all rational and irrational numbers.
  • Every natural number is an integer; every integer is rational; every rational number is real.
  • Irrational numbers (√2, π, e) cannot be written as ⟦p|q⟧; their decimals never end or repeat.
  • Absolute value: |a| = a if a ≥ 0 and |a| = −a if a < 0, so |−3| = 3.
  • A prime has exactly two factors; 1 is neither prime nor composite.
Example 1. Classify the numbers −3, 0.75, √2 and 0.333… (say which of ℕ, ℤ, ℚ, ℝ each belongs to).
  1. Recall the sets. ℕ = 1, 2, 3, … ; ℤ = whole numbers including negatives and 0; ℚ = numbers that can be written as ⟦a|b⟧ with a, b integers and b ≠ 0; ℝ = all of these plus the irrational numbers.
  2. −3. It is a whole number with a sign, so −3 ∈ ℤ. It is also rational, because −3 = ⟦−3|1⟧.
  3. 0.75. The decimal stops, so write it as a fraction: 0.75 = ⟦75|100⟧ = ⟦3|4⟧. So 0.75 ∈ ℚ.
  4. √2. 2 is not a perfect square, and the decimal 1.41421356… never stops or repeats. It cannot be written as ⟦a|b⟧, so √2 is irrational (it belongs to ℝ only).
  5. 0.333…. It repeats, so use a conversion. Let x = 0.333… Then 10x = 3.333… Subtract: 9x = 3, so x = ⟦1|3⟧. So 0.333… ∈ ℚ.
Answer: −3 ∈ ℤ, ℚ, ℝ; 0.75 ∈ ℚ, ℝ; √2 ∈ ℝ only (irrational); 0.333… ∈ ℚ, ℝ.
Example 2 (a simple proof). Prove that the sum of two even numbers is even.
  1. Define even. An even number is a multiple of 2, so it can be written 2k with k an integer.
  2. Name the two numbers. Let them be 2m and 2n, where m and n are integers.
  3. Add them. 2m + 2n = 2(m + n).
  4. Conclude. m + n is an integer, so 2(m + n) is a multiple of 2, which means it is even. ∎
Answer: The sum of two even numbers is always even.
Think: Is 0 even? Is the sum of an even and an odd number always odd? How would you prove it?

3History & Facts

  • Pythagoreans (about 500 BCE): discovered that √2 cannot be written as a fraction, a shock to their belief that all numbers are rational.
  • India (about 600 CE): zero and negative numbers were used in calculations by Brahmagupta.
  • Georg Cantor (1870s): showed that some infinite sets are larger than others.
  • Fact: the symbols ℕ, ℤ, ℚ come from German and Italian words: Zahlen (numbers) and quoziente (quotient).

5Real-World Applications

  • Computing: integers and real numbers are separate data types.
  • Measurement: lengths such as the diagonal of a square are irrational (√2 × side).
  • Finance: negative integers represent debts.

7Classwork & Homework

Classwork

  1. Which sets contain −5?
    Answerℤ, ℚ and ℝ (not ℕ).
  2. Write 0.8 as a fraction.
    Answer⟦8|10⟧ = ⟦4|5⟧.
  3. Evaluate |−9| + |4|.
    Answer13.
  4. Prove that the product of two odd numbers is odd.
    Answer(2m + 1)(2n + 1) = 4mn + 2m + 2n + 1 = 2(2mn + m + n) + 1, which is odd.

Homework

  1. Is √9 rational or irrational?
    Answer√9 = 3, so it is rational.
  2. Write 0.2̇ (0.222…) as a fraction.
    AnswerLet x = 0.222…; 10x − x = 2 → x = ⟦2|9⟧.
  3. Order from smallest to largest: ⟦1|2⟧, −0.7, √2, 0.
    Answer−0.7, 0, ⟦1|2⟧, √2.
  4. Give a counterexample: “the sum of two irrationals is irrational”.
    Answer√2 + (−√2) = 0, which is rational.
